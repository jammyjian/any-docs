# 第 7 章 变压器

本章讲解变压器的基本知识:变压器的工作原理(电磁感应)、基本结构(铁芯与绕组)、分类,以及变压器的运行维护要点和常用于安全用电的安全隔离变压器。

**本章考点**:变压器的变比公式 U1/U2 = N1/N2、电流与匝数成反比、油浸式变压器与干式变压器的区别、安全隔离变压器二次侧电压等级等。

## 学习提示

- 变比公式是高频考点,务必掌握正比/反比关系。
- 理解"变压器不能变换直流"这一特性,判断直流能否通过变压器。
