# 7.1 变压器的工作原理

## 本节导读

变压器是电力的"翻译官"——把电压升高或降低,却不改变电能总量。它是靠 2.6 节讲的**电磁感应(互感)**原理工作的。这一节讲核心公式**变比**,必须会算。

## 一、变压器是干什么的

**变压器**:利用电磁感应原理,把一种交流电压变成另一种交流电压的电气设备。

- **升压变压器**:电压升高(用于输电);
- **降压变压器**:电压降低(用于配电,如 10 kV → 0.4 kV);
- **隔离变压器**:电压不变,只做电气隔离。

## 二、基本结构:两个绕组 + 一个铁芯

变压器由**一次绕组(初级)、二次绕组(次级)**和**铁芯**组成:

```
  一次绕组(接电源)        铁芯(导磁)      二次绕组(接负载)
  ┌─────────┐       ┌──────────┐       ┌─────────┐
  │  N1 匝  │ ══════╪  ════════╪ ════ ═│  N2 匝  │
  └─────────┘       └──────────┘       └─────────┘
      U1、I1                              U2、I2
```

- **一次绕组**接交流电源,匝数 N1;
- **二次绕组**接负载,匝数 N2;
- 铁芯把磁场集中起来,提高效率。

## 三、工作原理:互感(核心!)

1. 一次绕组接交流电源 → 一次侧电流**交变** → 铁芯中磁通**交变**;
2. 交变磁通**同时穿过**二次绕组 → 二次绕组中感应出电动势(互感);
3. 二次绕组接上负载 → 有电流输出。

> ⚠️ 关键:**磁通必须"变"才能生电**。交流电流方向不断变化,磁通不断变化,才能持续感应;**直流电流不变化,磁通不变,不能感应出电压**——所以变压器只能变交流,不能变直流。

## 四、变比公式(必背、必算)

### 电压与匝数成正比

```
U1 / U2 = N1 / N2
```

电压之比等于匝数之比。二次匝数多于一次 → 升压;少于一次 → 降压。

### 电流与匝数成反比

```
I1 / I2 = N2 / N1
```

电流之比等于匝数的**反比**。也就是说:**电压升高的同时电流变小,电压降低的同时电流变大**。

### 功率守恒(理想情况)

```
U1 × I1 ≈ U2 × I2
```

> 💡 通俗理解:**变压器是"不增不减电能"的转换器**——它把"高电压小电流"变成"低电压大电流",或反过来,能量总量基本不变。就像用齿轮换速:转速变慢就力量变大。

## 五、计算例题

**例题**:一台降压变压器,一次侧电压 380 V,一次绕组匝数 1000 匝,二次绕组匝数 200 匝。求二次侧电压。

**解**:`U1/U2 = N1/N2`
`380/U2 = 1000/200`
`U2 = 380 × 200/1000 = 76 V`

## 六、考点提示

- ✅ **U1/U2 = N1/N2**(电压与匝数成正比)。
- ✅ **I1/I2 = N2/N1**(电流与匝数成反比)。
- ✅ 变压器只能变**交流**,不能变直流。
- ✅ 功率基本守恒:U1·I1 ≈ U2·I2。
- ⚠️ 易混点:电压跟匝数**正比**,电流跟匝数**反比**,别记反。

## 七、本节小结

- 变压器靠互感原理,靠"交变磁通"在二次绕组感应电压。
- 变比公式:电压正比于匝数、电流反比于匝数。
- 只能变换交流,不能变换直流。
