# 4.2 万用表

## 本节导读

万用表(多用表)是电工最常用的仪表,**一表多能**:测电压、电流、电阻都能干。这一节讲清万用表的结构、怎么接、怎么测,以及最重要的**安全注意事项**——用错了轻则烧表,重则伤人。

## 一、万用表能测什么

| 功能挡 | 测量内容 | 说明 |
|---|---|---|
| 直流电压挡 | 直流电压 | 注意正负极性 |
| 交流电压挡 | 交流电压 | 常用 220 V、380 V |
| 直流电流挡 | 直流电流 | 电流表要串联 |
| 欧姆挡 | 电阻 | **不能带电测量** |
| 交流电流挡(部分型号) | 交流电流 | — |

> ⚠️ 万用表最常测的是**电压和电阻**;测大电流一般用钳形表(4.3 节)更方便。

## 二、使用万用表的基本步骤

```
选挡 → 选量程 → 接入测量 → 读表 → 归零(拨到关闭或电压挡)
```

1. **选挡**:先确定测的是电压、电流还是电阻,拨到对应挡位;
2. **选量程**:先大后小,指针偏转在刻度 1/2~2/3 区域最准;
3. **接入**:
   - 测**电压**:表笔与被测电路**并联**(红表笔接正极/火线,黑表笔接负极/零线);
   - 测**电流**:表笔与被测电路**串联**(需断开电路串入);
   - 测**电阻**:被测电阻**断电**后测量;
4. **读表**:读数乘以倍率(如欧姆挡 ×100);
5. **用完归零**:把转换开关拨回**交流电压最高挡**或关闭挡,防止下次误用。

## 三、测电阻的特别要求

1. **必须断电测量**:严禁在带电设备上用欧姆挡测电阻,否则烧表;
2. **欧姆调零**:每次换挡后,先把两表笔短接,调节"欧姆调零旋钮"使指针指向 0 Ω;
3. 被测电阻两端不能与其他电路并联,否则读数不准。

## 四、安全注意事项(重点)

- ❌ **严禁用欧姆挡测量带电设备**;
- ❌ 测量时**手不能触碰表笔的金属端**(带电时);
- ✅ 测电压前确认量程,防止小量程测大电压烧表;
- ✅ 测直流时极性接反,指针会反打,可能损坏表头;
- ✅ 在带电设备上测量,保持安全距离,穿绝缘鞋、戴绝缘手套。

## 五、考点提示

- ✅ 测电压**并联**、测电流**串联**、测电阻**断电后测**。
- ✅ 欧姆挡测电阻前要**调零**(短接表笔)。
- ✅ 严禁带电测电阻。
- ⚠️ 易混点:并联/串联别接反——电压表并联(跨接)、电流表串联(串入)。

## 六、本节小结

- 万用表:选挡→选量程→接入→读数→归零。
- 测电阻必须断电、要调零;测电压并联;测电流串联。
- 带电测电阻是禁忌,会烧表甚至伤人。

## 七、自测练习

1. (判断)用万用表欧姆挡可以带电测量电路中的电阻。( )
2. (单选)测量电压时,万用表应与被测电路()。
   A. 串联　B. 并联　C. 串联并联均可　D. 不用接入
3. (判断)用欧姆挡测电阻前,应将两表笔短接并调节调零旋钮,使指针指到 0 Ω。( )
4. (单选)万用表用完应将转换开关拨回()。
   A. 欧姆挡　B. 交流电压最高挡　C. 直流电压挡　D. 任意挡
5. (判断)万用表测电压时,红表笔应接被测电路的正极(或火线)。( )
