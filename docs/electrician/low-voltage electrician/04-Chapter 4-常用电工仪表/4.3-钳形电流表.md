# 4.3 钳形电流表

## 本节导读

测电流最麻烦的是要**断开电路串进去**。钳形电流表解决了这个问题——它像一个"钳子",把导线往钳口里一夹,不用断电就能读出电流。这一节讲它的原理、用法和注意事项。

## 一、原理:为什么不用断电就能测

钳形电流表的基本结构,是一个可开合的**电流互感器**:

- 铁芯做成"钳口"形状,能把导线**夹进去**;
- 被测导线相当于互感器的**一次侧绕组**;
- 钳口上的线圈相当于**二次侧绕组**,感应出与被测电流成比例的电流;
- 表头读出电流值。

```
       ┌─────────┐
       │  铁芯    │
  ──────┤钳 口    ├─────► 被测导线从钳口穿过(相当于一次绕组)
       └────┬────┘
            │ 二次绕组 → 表头
```

> 💡 通俗理解:导线成了互感器的"一次侧",不用拆线、不用断电,夹进去就能"看到"电流。

## 二、使用方法

```
选挡(先大后小) → 开钳口 → 把导线置于钳口中央 → 合钳读数
```

1. **选量程**:先估电流,选大档再逐步换小档;
2. **开钳**:按下扳机张开钳口,把**被测导线**(单根)放入**钳口中央**;
3. **合钳**:使钳口**闭合紧密**,保持不动,读取读数;
4. 测量中若读数偏小,可换小档;若读数超量程,立即换大档。

> ⚠️ **只能夹单根导线**:如果同时夹住两根导线,两根导线的电流会相互抵消,读数错误甚至为零。

## 三、钳形电流表的类型

- 多数钳形电流表**只能测量交流电流**(交流钳形表);
- 部分型号(交直流两用钳形表)可测直流电流;
- 高档型号还能测电压、电阻(相当于"钳形万用表")。

## 四、注意事项

- 测量前确认量程合适,**从小电流开始**逐档调整;
- **钳口要清洁、闭合严密**,有油污或夹不紧会造成读数不准;
- 测量小电流时,可把导线在钳口上**绕几圈**,读数除以圈数即得实际电流;
- 不要测量**裸导线**时用手接触钳口,注意防护;
- 在带电线路上测量,注意安全距离,不要碰触其他带电部分。

## 五、考点提示

- ✅ 钳形电流表**不用断电、不用拆线**就能测电流,靠电流互感器原理。
- ✅ 只能**夹单根导线**,且要放在**钳口中央**。
- ✅ 多数钳形表**只能测交流**电流。
- ⚠️ 易混点:钳形表是"测电流"的,测电压/电阻用万用表。

## 六、本节小结

- 钳形电流表利用电流互感器原理,夹线即可测电流。
- 使用要点:单根导线、钳口中央、先大后小选量程。
- 多数型号只能测交流;测量中注意钳口清洁密合。
