# 第 4 章 常用电工仪表

本章介绍低压电工常用的测量仪表:仪表的基本概念(准确度、量程、误差),以及万用表、钳形电流表、兆欧表(绝缘电阻表)、电能表和接地电阻测量仪的结构原理与使用方法。

**本章考点**:兆欧表的倍率选择与转速(120 r/min)、测量前必须验电/放电、钳形表只能测量交流、万用表欧姆挡不能带电测量等,多与实操考核结合。

## 学习提示

- 仪表是理论+实操双考的内容,既要记原理,也要记操作流程与安全注意事项。
- 注意区分:钳形表测量电流、万用表测电压/电阻、兆欧表测绝缘电阻——用途别混。
