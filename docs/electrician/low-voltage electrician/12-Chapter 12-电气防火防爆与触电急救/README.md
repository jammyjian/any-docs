# 第 12 章 电气防火防爆与触电急救

本章讲解电气火灾的成因与预防、灭火方法与灭火器的选择使用(尤其带电灭火),以及触电事故的现场处理与心肺复苏急救方法。

**本章考点**:电气火灾不能用水/泡沫灭火器扑救,应选用干粉或二氧化碳灭火器;带电灭火与安全距离;发现触电后的"断电、挑开、绝缘"处置顺序;心肺复苏的按压频率(100~120 次/分)与深度等。

## 学习提示

- 灭火器选择是高频考点:电气火灾优先干粉灭火器。
- 心肺复苏的操作细节(频率、深度、位置)也是实操必考,务必记牢。
