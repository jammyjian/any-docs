# 第 8 章 三相异步电动机

本章讲解三相异步电动机的完整知识:结构(定子、转子)、工作原理(旋转磁场、转差率)、铭牌与接线方式(星形/三角形)、启动与控制(全压启动、降压启动、正反转控制),以及维护与常见故障判断。

**本章考点**:定子绕组通三相交流电产生旋转磁场、转差率公式、铭牌上 380V/Δ、220V/Y 的接线含义、电动机外壳接地、Y-△ 降压启动等,理论+实操双考。
