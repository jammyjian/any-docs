# 8.2 电动机的工作原理

## 本节导读

电动机为什么会转?一句话:**三相交流电 → 旋转磁场 → 转子被"拖着"转**。这一节讲清这四步,以及最重要的概念——**转差率**。理解了转差率,才算真正懂"异步"二字。

## 一、旋转磁场怎么来的

定子三相绕组在空间上**相差 120°**分布,通入三相交流电后,三个绕组的磁场随时间变化又互相叠加,合成一个**大小不变、位置不断旋转**的磁场——这就是**旋转磁场**。

- 旋转磁场的转速叫**同步转速**,用 n₁(或 ns)表示;
- 同步转速与电源频率 f 和磁极对数 p 有关:

```
n₁ = 60 × f / p
```

- f = 50 Hz,磁极对数 p = 1(两极电机)时,`n₁ = 60 × 50 / 1 = 3000 r/min`;
- p = 2(四极电机)时,`n₁ = 1500 r/min`。

> 💡 记忆:**电源频率越高、磁极越少,同步转速越快**。

## 二、转子怎么转起来(四步)

1. **定子产生旋转磁场**;
2. 旋转磁场**切割转子导条** → 转子导条中感应出**感应电流**(电磁感应);
3. 通电的转子导条处在磁场中 → 受到**安培力**;
4. 转子在力作用下**跟随磁场转动**。

```
三相交流电 ─► 定子旋转磁场 ─► 转子感应电流 ─► 转子受力转动
```

> 💡 通俗比喻:旋转磁场像一根"转动的磁棒",磁棒转起来,把旁边能导电的"鼠笼"带着转——这就是电动机"被磁场带着跑"的原理。

## 三、转差率(核心概念,必背)

**转差率 s**:描述转子转速 n 与同步转速 n₁ 的"差距":

```
s = (n₁ - n) / n₁
```

- 正常运行时,转子转速 **n 永远略小于同步转速 n₁**(转差率 s 很小,如 2%~5%);
- 因为转子必须"追不上"磁场,才能一直有磁通切割、一直有感应电流、一直有转动力矩——所以叫**异步**电动机;
- 若 n = n₁(s = 0),就没有相对运动、没有感应电流,转子反而**转不起来**。

> ⚠️ 高频考点:**异步电动机的转子转速小于同步转速**;"异步"就是这个"差"的由来。

## 四、额定转速与转差

- 电机铭牌上的**额定转速**就是正常负载下的转子转速;
- 例:四极电机(同步 1500 r/min)额定转速常为 1440 r/min 左右,转差率约 4%。

## 五、考点提示

- ✅ 同步转速 `n₁ = 60f/p`(f 越大、p 越小,转速越快)。
- ✅ **转子转速 < 同步转速**——这是"异步"的含义。
- ✅ 转差率 s = (n₁−n)/n₁,正常很小(约 2%~5%)。
- ⚠️ 易混点:同步转速(磁场转速)与转子转速(实际转速)是两个数,别混。

## 六、本节小结

- 三相交流电产生旋转磁场,转子靠感应电流受力转动。
- 同步转速 n₁ = 60f/p;转子转速 n 永远小于 n₁。
- 转差率 s = (n₁−n)/n₁,是异步电动机的"标志"。

   A. 3000 r/min　B. 1500 r/min　C. 1000 r/min　D. 750 r/min

   A. 较大(接近 1)　B. 很小　C. 等于 0　D. 大于 1
