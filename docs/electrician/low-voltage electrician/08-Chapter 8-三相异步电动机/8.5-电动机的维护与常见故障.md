# 8.5 电动机的维护与常见故障

## 本节导读

电机也会"生病"。这一节讲日常怎么保养,以及最常见的故障现象和原因判断——很多判断题就是"现象+原因"的连线题。

## 一、日常维护要点

1. **清洁**:定期清除电机表面灰尘、油污,保持通风散热良好;
2. **轴承润滑**:定期检查轴承,补加润滑脂,轴承异常要更换;
3. **绝缘检查**:定期用**兆欧表**测绕组绝缘电阻(停电后进行),绝缘下降要处理;
4. **外壳接地**:检查保护接地是否可靠、接线是否牢固;
5. **运行监视**:听声音、测温度、看电流,发现异常及时处理;
6. **环境**:防潮、防水、防尘,电机房(罩)保持通风。

## 二、常见故障现象与原因(重点)

| 故障现象 | 常见原因 |
|---|---|
| **不能启动** | 电源缺相、绕组断路、控制电路故障、负载卡死、电压过低 |
| **转速变慢/转无力** | 电压过低、过载、缺相、轴承卡阻 |
| **过热(烫手)** | 过载、通风不良、电压过高/过低、绕组短路或接地 |
| **异响/振动** | 轴承损坏、转子不平衡、联轴器不正、缺相 |
| **烧焦味** | 绕组过热烧毁(绝缘烧损) |

> ⚠️ **缺相运行是电机的大敌**:三相电源缺了一相,电动机仍可能"带病转"(但电流大增、发热严重),很快烧毁。所以三相电动机应有**缺相保护**,热继电器(三相型)带断相保护功能。

## 三、故障判断的顺序思路

```
先查电源(是否缺相/电压) → 再查机械(轴承/负载) → 后查绕组(绝缘/短路)
```

- **先外后内、先机械后电气**,一步步排查;
- 需要拆机、测绕组时,必须先**断电、验电、放电**。

## 四、检修安全要点

- 检修前**断开电源并验电**;
- 拆开接线盒前确认无电、并放电;
- 电动机绕组测量用兆欧表(500 V),测量前断电;
- 修好后**空载试转**,检查转向、声音、电流正常再带负载。

## 五、考点提示

- ✅ 电动机缺相运行会**过热烧毁**,要有缺相保护。
- ✅ 定期测绝缘电阻(兆欧表)、检查轴承、检查接地。
- ✅ 故障排查:"先电源、后机械、再绕组"。
- ⚠️ 易混点:过热的原因可能是过载、电压异常、缺相、通风不良等多种,判断要全面。

## 六、本节小结

- 维护四件事:清洁、轴承、绝缘、接地。
- 常见故障:不能启动、过热、异响、烧毁,原因要多角度排查。
- 缺相运行最伤电机,必须防。

   A. 万用表　B. 兆欧表　C. 钳形表　D. 电能表
3. (判断)电动机外壳保护接地应定期检查。( )
4. (单选)电动机通电后不转且发出"嗡嗡"声,最可能的原因是()。
   A. 缺相　B. 电压过高　C. 轴承润滑太好　D. 负载太轻
5. (判断)检修电动机前,应断开电源并验电。( )

5. **√**。断电、验电是检修的前提。
