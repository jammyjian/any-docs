# 8.1 电动机的结构

## 本节导读

三相异步电动机是工厂里的"动力之王",电风扇、水泵、机床、电梯……到处是它的身影。这一节先认识它的"身体结构":定子(固定部分)和转子(转动部分),以及鼠笼式与绕线式的区别。

## 一、电动机的两大部分:定子和转子

```
┌─────────────────────────────┐
│  机座(外壳)                  │
│  ┌───────────────────────┐  │
│  │ 定子(静止)             │  │  ← 定子铁芯 + 定子绕组
│  │    ┌─────────────┐    │  │
│  │    │ 转子(旋转)   │    │  │  ← 转子铁芯 + 转子绕组
│  │    └─────────────┘    │  │
│  └───────────────────────┘  │
│  端盖 + 轴承(支撑转子)       │
└─────────────────────────────┘
```

| 部分 | 构成 | 作用 |
|---|---|---|
| **定子** | 定子铁芯(硅钢片)+ 定子绕组(三相绕组) | 通三相交流电,产生**旋转磁场** |
| **转子** | 转子铁芯 + 转子绕组(笼条/绕组) | 在旋转磁场中受力转动,输出机械动力 |
| 机座、端盖、轴承 | 外壳、支撑、转动支撑 | 保护与支撑 |
| 气隙 | 定子与转子之间很小的间隙 | 越小磁路越紧,效率越高 |

> 💡 名字来由:定子"定"在原地,转子"转"起来。定子产生磁场"带动"转子转。

## 二、按转子结构分两类

### 1. 鼠笼式电动机(最常见)

转子绕组像**鼠笼**(笼条短路):

- 转子由**硅钢片**叠成铁芯,槽内放**铜(或铝)导条**,两端用短路环连成一体;
- 外观就像"鼠笼",所以叫鼠笼式。

**优点**:结构简单、坚固耐用、价格便宜、维护方便;
**缺点**:启动性能一般(启动电流大、启动转矩不大)。

### 2. 绕线式电动机

转子有**三相绕组**,通过集电环(滑环)与外部电阻连接:

- 可以串接电阻改善启动和调速性能;
- 结构复杂、价格高,用于**启动转矩要求高、需要调速**的场合(如起重机)。

> 💡 记忆:**"鼠笼简单便宜,绕线能调速好启"**。绝大多数普通场合用鼠笼式。

## 三、定子绕组的三相引出线

定子三相绕组(U 相、V 相、W 相)的六个出线端接在**接线盒**里,标号如下(第 8.3 节接线时要用):

```
U1、U2      V1、V2      W1、W2
(U相首尾)  (V相首尾)  (W相首尾)
```

## 四、考点提示

- ✅ 电动机两大组成部分:**定子**(产生旋转磁场)和**转子**(受力转动)。
- ✅ **鼠笼式**转子:结构简单、便宜、常用;绕线式:可调速、启转矩大。
- ✅ 定子、转子由**硅钢片**叠成,减小涡流损耗。
- ⚠️ 易混点:定子通三相电产生磁场(电→磁),转子被磁场带着转(磁→力),两个环节别混。

## 五、本节小结

- 三相异步电动机 = 定子(磁场)+ 转子(受力转动)。
- 转子分鼠笼式(常用)和绕线式(调速用)。
- 定子绕组六个出线端 U1U2、V1V2、W1W2 用于接线。
