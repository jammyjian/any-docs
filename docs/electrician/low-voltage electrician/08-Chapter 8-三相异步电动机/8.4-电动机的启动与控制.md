# 8.4 电动机的启动与控制

## 本节导读

电动机"一转就花很大力气"(启动电流大)。这一节讲怎么启动才安全——**直接启动**和**降压启动(重点:星三角)**——以及最常用的**点动、自锁、正反转**控制原理。这部分是理论和实操的"重头戏"。

## 一、启动电流问题

电动机启动瞬间,转子还没转起来、感应反电动势很小,启动电流可达额定电流的 **4~7 倍**:

- 频繁启动或启动电流过大,会冲击电网、发热烧电机;
- 所以大电动机不能直接启动,要**降压启动**。

## 二、直接启动(全压启动)

直接把额定电压加到电机上启动:

- 启动设备简单(一台断路器/接触器即可);
- 适用于**容量较小**的电动机(一般规定一定容量以下可以直接启动);
- 容量大、变压器容量小的地方,直接启动会引起电压明显波动。

## 三、降压启动(重点:星三角启动)

启动时先降低加在电机上的电压,减小启动电流,转速上来后再加全压。常见方法:

### 1. Y-△(星三角)降压启动

电动机正常运行时按**三角形(△)**接法,启动时先接成**星形(Y)**,再自动切换回三角形:

- 星形接法时,每相绕组电压只有三角形的 **1/√3(约 0.577)**;
- 启动电流减小到直接启动的 **约 1/3**;
- 启动后靠**时间继电器**延时,自动从 Y 切换成 △(5.6 节讲过);

```
启动:接成 Y(低压启动,电流小)──延时──► 切换:接成 △(全压运行)
```

> ⚠️ 注意:只有**铭牌标 △ 接法**的电动机才适合 Y-△ 降压启动(运行本来就是 △)。

### 2. 自耦变压器降压启动

通过自耦变压器降低启动电压,启动结束后切除变压器,加全压。用于较大容量电动机。

## 四、电动机的三种基本控制

### 1. 点动控制

按下按钮电动机转,松开就停(不保持):

```
按下启动按钮 → 接触器吸合 → 电动机转
松开按钮     → 接触器释放 → 电动机停
```

用于调试、点动(如对刀)。

### 2. 自锁(连续)控制

按下启动按钮,接触器吸合后,靠**接触器自身的辅助常开触点**保持吸合,松开按钮电机继续转;按**停止按钮**才停。

```
启动:按启动按钮 → 接触器吸合 → 自锁触点闭合保持
停止:按停止按钮 → 电路断开 → 接触器释放
```

> 💡 通俗理解:**自锁触点就是"自己锁住自己"**——接触器用自己的一对辅助触点"搂住"启动按钮的回路,让按钮松开后依然通电。这是最核心的控制概念,实操必考。

### 3. 正反转控制

电动机转向由**三相电源相序**决定。把任意**两根相线对调**,旋转磁场反向,电动机就反转:

```
正转:接触器 KM1(正常相序)
反转:接触器 KM2(对调两相)
```

注意:**正反转两个接触器不能同时吸合**,否则会造成**相间短路**——必须加**互锁**(电气互锁或机械互锁)。

> ⚠️ 判断题高频:正反转控制中,两个接触器**同时通电会导致电源相间短路**,必须互锁。

## 五、考点提示

- ✅ 启动电流为额定电流的 **4~7 倍**。
- ✅ **Y-△ 降压启动**:启动电流约为直接启动的 **1/3**,用于铭牌 △ 接法电机。
- ✅ **自锁**靠接触器自身的辅助常开触点。
- ✅ 正反转换相序(对调两根相线),必须**互锁**防止相间短路。
- ⚠️ 易混点:点动(松手停)vs 自锁(松手不停),区别就在有没有自锁触点。

## 六、本节小结

- 启动电流大(4~7 倍额定),大电机要降压启动。
- 星三角降压:Y 启动、△ 运行,电流降约 1/3。
- 点动、自锁、正反转是电动机控制三大基本功;正反转要互锁。
