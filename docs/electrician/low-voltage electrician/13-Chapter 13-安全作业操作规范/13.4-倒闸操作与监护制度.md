# 13.4 倒闸操作与监护制度

## 本节导读

"倒闸"就是拉合开关(闸),改变电气设备的运行状态。倒闸操作要求"两人操作、一人监护、唱票复诵"。这一节掌握操作票制度和倒闸的安全要求——这是安全管理的高频考点。

## 一、什么是倒闸操作

**倒闸操作**:拉开或合上开关(断路器、隔离开关),把设备从一种状态切换到另一种状态(送电、停电、检修)。

```
送电:先合隔离开关 ──► 后合断路器
停电:先拉断路器 ──► 后拉隔离开关
```

## 二、倒闸操作的基本原则(必背)

- **送电**时,先合**隔离开关**,后合**断路器**;
- **停电**时,先拉**断路器**,后拉**隔离开关**;

> 💡 为什么?**断路器能切断短路电流,隔离开关不能**。所以停电要先拉断路器(在可能带电情况下切断),隔离开关只能在无负荷(已断开电流)时拉;送电反之,先合隔离开关把"电源接上"但不带电流,最后合断路器才正式带电。

> ⚠️ 判断题高频:**严禁带负荷拉合隔离开关**;隔离开关不能切断负荷电流,只能在断路器断开之后拉。

## 三、操作票制度

- 倒闸操作按**操作票**进行:事先写好操作项目和顺序,按票逐项执行;
- **操作票是书面指令**,防止忘项、漏项、错项;
- 操作完毕**逐项打勾**,最后汇报;
- 发令人、受令人、操作人、监护人职责分明。

## 四、操作监护制度(两人操作)

- 倒闸操作一般由**两人进行**:**一人操作、一人监护**;
- 监护人负责**发令、监督**每一步是否正确,随时纠正错误;
- 操作时采用**唱票复诵制**:监护人唱票(念操作项目),操作人复诵(重复念),确认无误后**操作**;再核对状态;

```
监护人唱票(念操作内容) ──► 操作人复诵(大声重复) ──► 确认无误 ──► 操作
```

> 💡 通俗理解:**"唱票复诵"就像两人核对口令,防止一个人走神做错**——这是防止误操作的关键制度。

## 五、操作中的安全要求

- 操作前核对设备**名称、编号**,防找错设备;
- 操作时穿**绝缘鞋、戴绝缘手套**,使用相应绝缘工具;
- **雨天、雾天**尽量避免户外倒闸操作;
- 操作后检查设备状态、记录时间;
- 检修人员在场时,送电前确认**人员已撤离、工作票已终结**。

## 六、考点提示

- ✅ 送电:先合隔离开关、后合断路器;停电相反(先拉断路器、后拉隔离开关)。
- ✅ **隔离开关不能带负荷拉合**。
- ✅ 倒闸操作按**操作票**进行,两人操作、一人监护。
- ✅ **唱票复诵**防误操作。
- ⚠️ 易混点:断路器(能带负荷开断)与隔离开关(只能无负荷开断)的先后顺序——先断器后刀闸停电,先刀闸后断器送电。

## 七、本节小结

- 倒闸操作有严格顺序:停电先拉断路器、送电先合隔离开关。
- 操作票 + 两人监护 + 唱票复诵,层层防错。
- 隔离开关严禁带负荷拉合。
