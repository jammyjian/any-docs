# 13.1 安全作业组织措施与技术措施

## 本节导读

电工作业要"双保险":一是靠**制度管人**(组织措施),二是靠**操作保命**(技术措施)。这一节掌握"保证安全的组织措施"和"技术措施"各有哪些——这是安全知识考核的高频考点。

## 一、保证安全的组织措施(制度层面)

靠规章制度把"谁能干、怎么批、谁来看着干、干到哪一步"规定清楚:

| 措施 | 内容 |
|---|---|
| **工作票制度** | 作业前填写工作票,明确任务、地点、安全措施,经批准才开工 |
| **工作许可制度** | 工作负责人得到许可后,现场确认安全措施到位才能开工 |
| **工作监护制度** | 作业时有专人监护,监护人不离岗、不兼做其他工作 |
| **工作间断、转移和终结制度** | 间断、换地点、收工都要办理相应手续,终结后恢复送电 |

> 💡 通俗理解:**"先审批、再许可、有人监护、有始有终"**——组织措施是用流程堵住疏忽。

> ⚠️ 判断题常考:低压电气作业也要执行工作票、许可、监护等制度;工作负责人不能兼任与工作无关的事。

## 二、保证安全的技术措施(操作层面)

靠**动手操作**让设备真正没电、确认没电、防止误送电。国家规范规定的技术措施是"**停电、验电、装设接地线、悬挂标示牌和装设遮栏**"(顺序记住):

```
停电 ──► 验电 ──► 装设接地线 ──► 悬挂标示牌、装设遮栏
```

| 技术措施 | 干什么 |
|---|---|
| **停电** | 断开检修设备电源,有明显的断开点(拉开隔离开关/断路器) |
| **验电** | 用合格验电器确认设备确实无电(验电器先在有电设备上验证是否好用) |
| **装设接地线** | 在检修设备两端(或可能来电侧)装设接地线,泄放残余电荷、防突然来电 |
| **悬挂标示牌、装设遮栏** | 挂"禁止合闸,有人工作"等标示牌,设遮栏防止误入、误送电 |

> 💡 记忆口诀:**"停、验、挂(接地线)、牌、栏"**。四项技术措施的顺序和内容是必背考点。

## 三、组织措施与技术措施的关系

- **组织措施**管"人":谁来干、怎么批、怎么监护;
- **技术措施**管"电":让设备确实无电、可靠接地、有人守护;
- 两者缺一不可:光有制度不操作,电还是带电;光会操作没制度,容易乱干。

## 四、考点提示

- ✅ 组织措施:工作票、许可、监护、间断/转移/终结制度。
- ✅ 技术措施(必背):**停电、验电、装设接地线、悬挂标示牌和装设遮栏**。
- ✅ 技术措施有**顺序**:先停、后验、再接地、最后挂牌设栏。
- ⚠️ 易混点:组织措施(管人)与技术措施(管电)别混,考题常让"挑出属于技术措施的一项"。

## 五、本节小结

- 组织措施靠制度管人:票、许可、监护、终结。
- 技术措施靠操作管电:停、验、挂地线、牌栏。
- 两者结合,才构成完整的安全作业保障。

## 六、自测练习

1. (单选)下列属于保证安全的技术措施的是()。
   A. 工作票制度　B. 验电　C. 工作监护制度　D. 工作许可制度
2. (判断)保证安全的技术措施包括停电、验电、装设接地线、悬挂标示牌和装设遮栏。( )
3. (判断)验电时,验电器应先在带电设备上验证其是否完好。( )
4. (单选)下列属于保证安全的组织措施的是()。
   A. 停电　B. 装设接地线　C. 工作票制度　D. 悬挂标示牌
5. (判断)装设接地线的作用是泄放残余电荷、防止突然来电,保护检修人员。( )

<details>
<summary>参考答案(点击展开)</summary>

1. **B**。验电是技术措施;其余是组织措施。
2. **√**。停、验、挂地线、牌栏四项技术措施。
3. **√**。先在有电设备上验证验电器完好。
4. **C**。工作票制度属组织措施。
5. **√**。接地线泄放电荷、防突然来电。
