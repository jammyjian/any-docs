# 第 13 章 安全作业操作规范

本章讲解低压电工现场作业必须遵守的安全规范:安全作业的组织措施(工作票制度、工作许可、监护)与技术措施(停电、验电、装设接地线、悬挂标示牌和装设遮栏),以及安全用具的使用和倒闸操作规范。

**本章考点**:停电、验电、挂地线的顺序、"先接接地端,后接导体端"、装设接地线的规定、低压带电作业的安全要求、验电器使用前先验明自身完好等。
