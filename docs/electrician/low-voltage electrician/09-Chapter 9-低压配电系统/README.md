# 第 9 章 低压配电系统

本章讲解电力系统与低压配电的基本知识:电力系统的组成与供电方式、低压配电系统的接地形式(TN-S、TN-C、TN-C-S、TT、IT 五种系统)、配电箱与配电柜,以及电工识图基础。

**本章考点**:五种接地形式的区别与代号含义、TN-C 系统中保护线与中性线合一(PEN 线)、配电箱内各回路的配置、电工图形符号与文字符号等,是机考难点和高频考点。

- 五种接地形式是全书最难记的部分之一,建议画图对比记忆:第一个字母表示电源中性点接地情况(T=直接接地),第二个字母表示用电设备外壳接地情况。
- 识图能力直接影响第 13、14 章的学习,务必打好基础。
