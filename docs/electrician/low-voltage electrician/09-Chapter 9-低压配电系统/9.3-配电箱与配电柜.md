# 9.3 配电箱与配电柜

## 本节导读

配电箱和配电柜是"电的分发站":总开关把电接进来,分路开关把电送出去。这一节认识它们的组成、基本配置和安全要求。

## 一、配电箱的作用与组成

**配电箱(柜)**:集中安装开关、保护电器、测量仪表的成套低压配电装置,把总电源分配给各分路负荷。

```
进线(总开关) ──► 母线 ──► 分路开关1 ──► 回路1
                        ├─ 分路开关2 ──► 回路2
                        └─ 分路开关3 ──► 回路3
```

主要组成:

| 元件 | 作用 |
|---|---|
| **总开关**(隔离开关/总断路器) | 接通、断开总电源,方便检修 |
| **分路断路器/熔断器** | 每条支路的保护(短路、过载) |
| **母线(汇流排)** | 把电能汇集后分配给各分路 |
| **漏电保护器** | 漏电、人身触电保护(插座回路必配) |
| **电流表/电压表** | 监视电流、电压 |

## 二、配电箱(柜)的基本配置要求

- 每个回路都要有**过载和短路保护**(断路器或熔断器);
- 插座回路、移动设备回路要装**漏电保护器**;
- 箱(柜)的**金属外壳要可靠接地**(接 PE 线);
- 导线颜色区分:**相线**用黄、绿、红,**中性线(N)用淡蓝色,保护零线(PE)用黄绿双色**;
- 箱内导线要**分色、扎紧、编号**,进出线要有余量。

> ⚠️ 判断题常考:**中性线(N)淡蓝色、保护零线(PE)黄绿双色**——颜色不能混。

## 三、配电箱(柜)安装与使用要求

- 安装牢固、通风干燥,箱门要能正常开关;
- **箱内不得堆放杂物**,元件间留足散热空间;
- 箱前要留操作空间,标明回路名称、编号;
- 检修时**先断总开关,再验电**,确认无电再操作;
- 定期检查接线是否松动、发热,漏电保护器要**定期试验(按"试验按钮")**。

> 💡 漏电保护器每月应**按一次试验按钮**检查能否正常跳闸。

## 四、配电箱与配电柜的区别(简说)

- **配电箱**:小型的、容量较小的配电装置,常装在墙上、室内;
- **配电柜(屏、盘)**:容量较大、元件较多,常立式安装(如低压配电柜),用于变电所或厂房。

> 💡 本质相同(都是配电装置),只是大小、安装形式不同。

## 五、考点提示

- ✅ 每个回路都应有**过载和短路保护**;插座回路装**漏电保护**。
- ✅ 配电箱金属外壳**接地**;箱内导线**分色**。
- ✅ N 线淡蓝色,PE 线黄绿双色,相线黄/绿/红。
- ⚠️ 易混点:总开关负责总切断,分路开关负责支路保护,漏电保护负责人身漏电安全——职责不同。

## 六、本节小结

- 配电箱是"电的分发站":总开关 + 母线 + 分路开关 + 保护。
- 每个回路要保护,插座回路要漏电保护,外壳要接地。
- 导线分色规范:相线黄绿红、N 淡蓝、PE 黄绿双色。
