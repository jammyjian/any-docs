# 9.4 电工识图基础

## 本节导读

电工图纸是"电气世界的说明书"。这一节掌握三类电气图、常用图形符号和文字符号,学会怎么"看图"——这是读懂电路、正确接线的基础,也是考试必考点。

## 一、电气图的三种主要形式

| 形式 | 画什么 | 用途 |
|---|---|---|
| **电路原理图** | 用符号表示电路连接关系、工作原理 | 分析电路、看原理 |
| **接线图(安装图)** | 表示元件实际安装位置和接线 | 现场接线、安装 |
| **布置图(位置图)** | 表示设备、元件的平面位置 | 规划安装位置 |

> 💡 原理图"讲道理",接线图"讲怎么接",布置图"讲装哪"。

## 二、常用电气图形符号(必背)

| 元件 | 图形符号(简记) | 文字符号 |
|---|---|---|
| 电动机 | 圆圈内 M | **M** |
| 变压器 | 两个绕组线圈 | **T** |
| 熔断器 | 方框内 X/矩形中一横 | **FU** |
| 断路器(低压) | 带触点的开关 | **QF** |
| 隔离开关 | 刀开关 | **QS** |
| 接触器 | 方框表示线圈,**KM**;触点另画 | **KM** |
| 热继电器 | 方框内 L/加热元件 | **FR** |
| 中间/时间继电器 | 方框内 KA/KT | **KA / KT** |
| 按钮(启动/停止) | 常开/常闭按钮 | **SB** |
| 行程开关 | 限位开关 | **SQ** |
| 电流互感器 | 两个铁芯圈 | **TA(CT)** |
| 电压互感器 | 两个铁芯圈 | **TV(PT)** |
| 信号灯 | 圆圈内 X(红/绿) | **HL** |
| 整流二极管 | 三角+竖线 | **V** |

> ⚠️ 高频判断:**接触器用 KM,热继电器用 FR,熔断器用 FU,断路器用 QF,按钮用 SB**,这些文字符号必须记牢。

## 三、三相电源线路的标注

- 相线:**L1、L2、L3**(旧标 A、B、C 或黄、绿、红);
- 中性线:**N**(淡蓝色);
- 保护零线:**PE**(黄绿双色);
- 电气设备接线端子常用:**U、V、W**(三相绕组端),数字表示辅助触点编号。

## 四、怎么"看图"的步骤

1. **先看主电路(一次回路)**:从电源 → 开关 → 熔断器/断路器 → 接触器主触点 → 热继电器 → 电动机,弄清楚"电走哪条路";
2. **再看控制电路(二次回路)**:从一根电源线 → 按钮 → 接触器线圈 → 回到另一根电源线,弄清楚"怎么控制";
3. **找关联**:看接触器 KM 的辅助触点在哪里,热继电器 FR 的常闭触点串在控制电路哪里;
4. **看保护**:漏电保护、短路保护、过载保护是怎么接的。

```
主电路: L1→QS→FU→KM主触点→FR→M
控制电路: L→SB1→SB2→KM线圈→FR常闭→L
         (按钮启动 停止 接触器 过载保护)
```

> 💡 看懂一个图的诀窍:**主电路看"谁给电动机送电",控制电路看"谁让主电路通断"**。

## 五、电路图中"线"的颜色与粗细

- 主电路导线通常画**粗实线**,控制电路画细实线;
- 不同功能回路用不同编号、不同颜色区分。

## 六、考点提示

- ✅ 图形符号:电动机 M、变压器 T、熔断器 FU、断路器 QF、隔离开关 QS、接触器 KM、热继电器 FR、按钮 SB。
- ✅ 相线 L1L2L3、中性线 N、保护线 PE。
- ✅ 看图顺序:先主电路、后控制电路。
- ⚠️ 易混点:KM(接触器)与 KA(继电器)、QF(断路器)与 QS(隔离开关)的文字符号别记混。

## 七、本节小结

- 电气图有原理图、接线图、布置图三种。
- 记住常用元件的图形符号和文字符号。
- 看图先看主电路、再看控制电路、再找关联与保护。
