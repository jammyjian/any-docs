# 5.4 交流接触器

## 本节导读

接触器是电气控制的"总开关"——用一个小线圈的电流,控制大电流主电路的通断,还能实现**远距离控制、频繁操作、自动控制**。电动机的点动、自锁、正反转控制全靠它。这一节讲清它的结构和工作原理。

## 一、接触器是干什么的

**交流接触器**:利用**电磁铁原理**,用**小电流控制大电流**的自动电器。

- 线圈电流小(控制回路),主电路电流大(主回路);
- 可以实现:按钮远距离控制、自动/顺序控制、频繁启停电动机。

## 二、结构组成

```
控制回路(小电流)             主回路(大电流)
  线圈 ──► 电磁铁吸合 ──► 主触头闭合 ──► 电动机通电
```

主要部件:

| 部件 | 作用 |
|---|---|
| **电磁系统** | 线圈、铁芯、衔铁——线圈通电产生磁力吸合衔铁 |
| **触头系统** | 主触头(通断主电路,容量大)+ 辅助触头(用于控制回路) |
| **灭弧系统** | 熄灭主触头分断时的电弧 |
| **复位弹簧** | 线圈断电后,弹簧把衔铁弹回,触头断开 |

**触头的两种状态(必背)**:
- **常开触头(NO)**:线圈不通电时断开,通电后闭合;
- **常闭触头(NC)**:线圈不通电时闭合,通电后断开。

> ⚠️ 判断题高频:"常开触头"在线圈不通电时是断开的;"常闭触头"不通电时是闭合的。注意"常开/常闭"指的是**断电状态**。

## 三、工作原理

1. **吸合**:线圈通电 → 铁芯产生磁力 → 吸合衔铁 → 主触头闭合 → 主电路接通;
2. **保持**:线圈持续通电,触头保持闭合;
3. **释放**:线圈断电 → 磁力消失 → 弹簧复位 → 主触头断开 → 主电路断电。

> 💡 **水流类比**:线圈是"阀门开关",主触头是"主管道阀门"。用小开关控制线圈,就能间接控制大阀门——这就是"小电流控制大电流"。

## 四、主要参数与型号

- **额定电压**:触头能承受的电压(如 380 V);
- **额定电流**:主触头能长期通过的电流;
- **线圈电压**:线圈额定工作电压(常见 36 V、110 V、220 V、380 V);
- **操作频率**:每小时允许的操作次数。

**型号**:CJ 系列(CJX2、CJ20 等),C 表示接触器,J 表示交流。

## 五、选用要点

1. 接触器额定电压、额定电流 ≥ 主电路要求;
2. 线圈电压与**控制回路电源**一致;
3. 按操作频率选型(频繁操作选允许频率高的)。

## 六、考点提示

- ✅ 接触器靠电磁原理,**小电流控制大电流**。
- ✅ 常开(NO)断电断开、通电闭合;常闭(NC)断电闭合、通电断开。
- ✅ 线圈断电 → 弹簧复位 → 触头断开,主电路断电。
- ⚠️ 易混点:常开/常闭的"常"指断电状态,别按通电状态记。

## 七、本节小结

- 交流接触器 = 电磁铁 + 触头,实现远距离、自动控制。
- 主触头通断主电路,辅助触头用于控制回路。
- 常开常闭触头按"断电状态"定义。
