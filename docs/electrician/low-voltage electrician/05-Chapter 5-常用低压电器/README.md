# 第 5 章 常用低压电器

本章系统讲解低压配电与控制电路中常用的电器元件:低压电器的分类与技术要求,以及熔断器、低压断路器、交流接触器、热继电器、中间继电器、时间继电器、主令电器和漏电保护器的结构、工作原理、型号含义与选用。

**本章考点**:接触器的常开/常闭触头、热继电器的"热"原理(双金属片)、熔断器的作用是短路保护、漏电保护器的动作电流(30 mA)等,是机考题量最大的章节之一。

## 学习提示

- 低压电器种类多、型号杂,重点是理解"每一种电器保护什么、怎么动作"。
- 热继电器=过载保护,熔断器=短路保护,漏电保护器=漏电保护——三者别混淆。
