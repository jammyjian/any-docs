# 5.2 熔断器

## 本节导读

熔断器是最简单、最古老的保护电器——"电流太大就烧断自己,切断电路"。它是**短路保护**的主力,家里的保险丝、配电箱里的熔芯都是它。这一节讲原理、类型、型号和选用。

## 一、作用:短路保护

熔断器串联在电路中,当电路发生**短路**或严重过载时,电流急剧增大,熔体发热**熔断**,切断电路,保护设备和线路。

> ⚠️ 重点:**熔断器是短路保护**,一般**不能作电动机的过载保护**(电动机启动电流大,熔断器会误断)——过载保护靠热继电器(5.5 节)。

## 二、工作原理

熔体(保险丝)是低熔点金属(铅、锡合金或银、铜丝):

- 正常工作时,电流小,熔体不发热(或散热足够),保持完好;
- 短路时电流猛增,熔体发热量 `Q = I²Rt` 剧增(电流平方!),温度骤升到熔点,**熔断**切断电路。

```
正常:  电流小 ───────[熔体]───────► 负载   → 电路正常
短路:  电流大 → 熔体迅速熔断,电路断开  → 设备被保护
```

## 三、类型与型号

| 类型 | 特点 | 典型型号 |
|---|---|---|
| 瓷插式 | 老式,用于小电流照明线路 | RC1A |
| 螺旋式 | 带熔断指示,分断能力较高 | RL1、RL6 |
| 管式(有填料) | 分断能力高,用于大电流配电 | RT0、RT14 |
| 快速熔断器 | 动作快,保护半导体元件 | RS0、RS3 |

**型号含义**(以 RL1-15 为例):

```
R  L  1 - 15
│  │     └─ 熔断器额定电流(A)
│  └─ 设计序号
└─ 类型代号:R=熔断器;L=螺旋式;C=瓷插式;T=有填料管式;S=快速
```

> 💡 记住**第一个字母 R 代表熔断器**就够应付大部分题型;再记 L(螺旋)、T(管式)。

## 四、选用原则

1. **额定电压**:等于或大于电路额定电压;
2. **额定电流**:熔体电流 ≥ 电路正常工作电流(留适当余量);
3. **分级配合**:同一供电链路上,越靠近电源的熔断器额定电流越大(上级熔断,下级才能先断),保证**选择性**;
4. 保护电动机时,熔体电流要按电动机启动电流考虑,不能按额定电流简单选取。

## 五、使用注意事项

- 更换熔体时必须**断电**后进行,禁止带电换保险;
- 熔体烧断后,先**查明原因**(短路还是过载),排除故障再更换,**不得用铜丝铁丝代替**保险丝;
- 熔断器应与电路匹配,过大不起保护作用,过小频繁熔断。

> ⚠️ 判断题高频:**用铜丝代替熔断器熔体是错误且危险的**(铜丝熔点高、熔断特性差,短路时不能可靠断开)。

## 六、考点提示

- ✅ 熔断器 = **短路保护**。
- ✅ 熔体电流选择与分级配合(靠近电源的额定电流更大)。
- ✅ **禁止用铜丝、铁丝代替熔体**。
- ⚠️ 易混点:熔断器不能代替热继电器做电动机过载保护。

## 七、本节小结

- 熔断器靠"大电流熔断熔体"实现短路保护。
- 型号第一个字母 R;类型有瓷插、螺旋、管式、快速。
- 选用要分级配合,更换前先断电、先查故障。
