# 11.2 接地与接零保护

## 本节导读

"接地"和"接零"是低压配电两大安全保护,常考且易混。这一节先分清各种"接地"的名词,再重点讲**保护接地**和**保护接零**的原理与区别。

## 一、各种接地的分类

| 接地类型 | 干什么的 |
|---|---|
| **工作接地** | 电源中性点接地,保证系统正常运行(如变压器中性点直接接地) |
| **保护接地** | 设备金属外壳接地,防外壳带电伤人 |
| **保护接零** | 设备金属外壳接保护零线(PE),TN 系统用 |
| **重复接地** | 保护零线(或中性线)在配电中途多处再次接地 |
| **防雷接地** | 防雷装置入地泄放雷电流 |
| **屏蔽接地** | 屏蔽层接地,防干扰 |

> 💡 **工作接地保"运行",保护接地保"人身"**——一个为电,一个为人。

## 二、保护接地(TT 系统的做法)

**把设备金属外壳直接与大地(接地极)连接**:

- 设备漏电 → 外壳带电 → 电流经外壳流人地(外壳与大地电位近似相等);
- 人接触外壳时,由于人与外壳并联但人体电阻远大于接地电阻,通过人体的电流很小,得到保护;

```
设备外壳 ──► 接地极 ──► 大地(泄流)
        ──► 人(并联,电流很小)
```

用于**电源中性点不接地或独立接地的系统(TT、IT)**。

## 三、保护接零(TN 系统的做法)

**把设备金属外壳接保护零线(PE 线)**:

- 设备漏电 → 外壳 → PE 线 → 中性点 → 形成**单相短路**;
- 短路电流很大 → 促使保护装置(熔断器/断路器)**迅速跳闸**,切断故障设备;
- 故障设备失电,人就不触电。

```
设备漏电 ──► 外壳 ──► PE线 ──► 短路大电流 ──► 保护装置跳闸停电
```

用于**电源中性点直接接地的系统(TN 系统)**。

> 💡 通俗对比:**接地是"把电压拉低让人安全",接零是"把漏电变成短路让开关跳闸"**。

## 四、接零与接地不能混用(必考)

在同一低压电网(同一变压器供电范围)内:

- **不允许一部分设备接零、一部分设备接地**;
- 否则,接地的设备漏电时,外壳经大地→电源中性点形成回路,使**整个接零系统的零线电位升高**,所有接零设备外壳都带上危险电压。

> ⚠️ 判断题高频:**同一低压电网内,保护接零和保护接地不能混用**。

## 五、重复接地

- 在 TN 系统中,保护零线(或 PEN 线)除中性点接地外,**在配电线路的中段、末端再接地**;
- 好处:PEN(零)线断线时,断点之后的设备外壳仍经重复接地与大地连接,降低触电危险。

> 💡 通俗理解:零线"一路走一路补接地",防止零线断了之后后面的设备外壳"悬空带电"。

## 六、考点提示

- ✅ 工作接地=电源中性点接地;保护接地/接零=设备外壳保护。
- ✅ **保护接地**:外壳直接入地,用于 TT/IT;
- ✅ **保护接零**:外壳接 PE 线,漏电变短路促跳闸,用于 TN。
- ✅ **接零与接地不能混用**。
- ⚠️ 易混点:接零(接中性线回路,靠跳闸)与接地(接大地,靠限流)原理不同、系统不同。

## 七、本节小结

- 接地分工作、保护、重复、防雷等多种,作用各不相同。
- 保护接地把漏电引向大地;保护接零把漏电变短路跳闸。
- TN 系统接零、TT 系统接地,同一电网内不能混用。
