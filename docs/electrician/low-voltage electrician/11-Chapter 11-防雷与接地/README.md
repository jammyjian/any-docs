# 第 11 章 防雷与接地

本章讲解雷电的危害与防雷装置(避雷针、避雷器、防雷接地)、接地与接零保护的区别与应用(工作接地、保护接地、重复接地、保护接零)、接地装置的安装与检测要求。

**本章考点**:接地电阻的合格值(≤10 Ω 等)、保护接地 vs 保护接零的适用场合、同一配电系统不能部分接地部分接零、重复接地的作用等,是机考高频考点。

## 学习提示

- 保护接地和保护接零是最容易混淆的考点,务必从"系统接地形式"的角度理解其区别。
- 记住:同一台设备上,保护接地与保护接零不能同时使用。
