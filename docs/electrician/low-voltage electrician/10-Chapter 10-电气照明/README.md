# 第 10 章 电气照明

本章讲解电气照明的基本知识:照明的基本概念与质量指标(照度、色温、显色性)、常用光源与灯具(白炽灯、荧光灯、LED 灯、卤钨灯等)、照明线路的安装要求,以及常见照明故障的检修思路。

**本章考点**:荧光灯(日光灯)的启辉器与镇流器工作原理、LED 灯的优点、白炽灯只能串联限流电阻、照明线路保护(短路/过载/漏电)等。

## 学习提示

- 荧光灯电路是常考点:启辉器负责启动、镇流器负责限流与产生高压,记住两者的角色。
- 照明故障检修考"先电源后负载、先外线后内线"的排查思路。
