# 14.6 理论机考题型与答题技巧

## 本节导读

理论是**电脑答题**,题量不小、及格线不低。这一节摸清题型结构,掌握"判断+单选"的答题技巧和复习重点,助你稳稳过线。

## 一、理论机考的一般情况

| 项目 | 说明 |
|---|---|
| 考试形式 | 电脑机考,当场出分 |
| 题型 | 判断题 + 单选题(部分地方有少量多选题) |
| 题量 | 一般 100 题左右 |
| 满分/及格 | 满分 100 分,**80 分及格**(各地以考务通知为准) |
| 考试范围 | 法律法规、基础知识、安全技术、急救实操理论等 |

> ⚠️ 以当地**报名机构的考务说明**为准;机考答题要注意时间分配,别在一道题上纠结太久。

## 二、判断题答题技巧

1. **看绝对词**:出现"**一定、必须、肯定、任何、全部、绝对、禁止**"等绝对化表述时,多长个心眼——很多是错的(但也要结合知识点判断,如"开关必须接火线"这类本身就是绝对正确);
2. **抓安全常识**:涉及"带电作业、徒手拉触电者、接零接地混用"等安全底线,考的是"对不对",安全红线都是"错"的方向;
3. **抓关键词**:"短路产生大电流、验电先验证、接地线先接地端"等**规范动作**,一般是"对"。

## 三、单选题答题技巧

- **排除法**:先排除明显错误项(与安全常识相悖、数值离谱的);
- **数值题靠记忆**:安全电压等级、电流阈值(1/10/50mA)、接地电阻(4Ω/10Ω)、同步转速公式等,背熟;
- **看"最/首先/应"**:题干问"首先应""最主要""应选用"时,选规范流程的第一步或最标准的做法;
- **遇到不会的**:结合"安全第一"原则选,不要空着不选。

## 四、高频考点清单(背这些就够)

| 模块 | 常考知识点 |
|---|---|
| 法规 | 特种作业人员条件(18 岁以上、健康)、证书 6 年有效期、3 年复审 |
| 电工基础 | 欧姆定律、串并联、交流电频率 50Hz、220V 有效值、三相 380V |
| 安全技术 | 安全电压 42/36/24/12/6、安全电流 1/10/50mA、接地电阻、漏电保护 |
| 电器 | 断路器、接触器、热继电器、熔断器的作用和符号 |
| 电机 | 异步原理、转差率、Y/△ 接法、启动与反转 |
| 急救防火 | 先断电、干粉灭火、心肺复苏 30:2、触电先脱离电源 |

## 五、复习策略建议

1. **先过一遍本套文档的"考点提示"**,把 ✅ 必背点背熟;
2. **做自测练习**:每节末尾的练习题相当于"仿真题",做错的知识点回到正文看;
3. **错题归因**:把做错的题按"数值记不住 / 概念混淆 / 粗心"分类,针对性补;
4. **考前两天**:重点再过一遍安全技术、急救、法规三个板块。

## 六、考点提示

- ✅ 理论机考:判断+单选,满分 100,80 分及格(以当地通知为准)。
- ✅ 答题技巧:排除法、抓关键词、结合"安全第一"。
- ✅ 高频必背:安全电压/电流数值、接地电阻、心肺复苏比例、证书有效期。
- ⚠️ 易混点:别把理论当"纯背",要理解"为什么"——理解了的题,换着问法也不会错。

## 七、本节小结

- 题型:判断+单选,机考当场出分,80 分及格。
- 技巧:排除法、抓绝对词、结合安全常识。
- 复习:背熟考点清单 + 做完自测练习 + 错题归因。
