# 第 14 章 实操考核与应试技巧

本章面向低压电工实操考核与理论机考,以"知识讲解"的方式介绍实操考核的科目与评分标准、各类实操的要点(仪表使用、电动机控制线路、配电线路与电能表接线、安全操作与触电急救),以及理论机考的题型与答题技巧。

**本章考点**:实操考核的扣分项(如不验电直接作业、接线错误、急救动作不规范)、机考的答题策略(判断题优先、时间分配)等。

## 学习提示

- 实操考核重在"规范动作",读这一章时要在脑中"过一遍"整个操作流程。
- 理论机考时间充裕但题量大,先做有把握的判断题和单选题。
