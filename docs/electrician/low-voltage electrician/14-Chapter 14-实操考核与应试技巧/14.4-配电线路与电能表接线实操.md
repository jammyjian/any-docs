# 14.4 配电线路与电能表接线实操

## 本节导读

配电箱接线、电能表接线是实操考核常见项目。这一节掌握照明线路、插座、单相和三相电能表的正确接法,接线要"对号入座"。

## 一、配电线路(照明/插座)接线要点

- **火线(L)进开关**,零线(N)进灯头;开关必须接在火线上;
- 插座:**左零右火上接地**(面对插座),三孔插座上孔接 PE;
- 灯具螺口:**火线接中心触点,零线接螺纹**;
- 导线分色规范:相线黄/绿/红、N 淡蓝、PE 黄绿双色;
- 接线牢固,铜导线压接到位,不外露。

```
进线: L ──► 开关 ──► 灯具 ──► N
       L ──► 插座左? 不,左孔N、右孔L
插座(面对): 左孔─N   右孔─L   上孔─PE
```

## 二、单相电能表(家用电度表)的接线

常用**直接接入**方式(小电流、直接测量):

```
进线: L ──► 电能表 1(相线进)──► 2(相线出)──► 负载
       N ──► 电能表 3(零线进)──► 4(零线出)──► 负载
```

以常见单相表(1、3 进,2、4 出)为例:

- 表尾 1、3 接**进线**(1 火、3 零);
- 表尾 2、4 接**出线**(2 火、4 零);
- 电能表**接线顺序不能反**:火线必须经电流线圈,零线经电压回路。

> ⚠️ 判断题常考:**单相电能表接线时火线、零线进出不能颠倒**(接反会使表不走或计量错误)。

## 三、三相电能表的接线

- **三相四线有功电能表**有 11 个端子(或按说明书):三组电流、电压分别对应 L1、L2、L3、N;
- 电流线圈**串接**在相线中,电压线圈**并接**在相线对 N 之间;
- 常用**互感器接入**时,电流互感器 TA 串接,注意**同名端**和极性;
- 接线后核对**表号和相序**,不能接错相。

> 💡 记住:**电流线圈串联、电压线圈并联**,这是电能表接线的总原则。

## 四、接线检查与试车

- 接完后对照原理图/表尾接线图**逐点核对**;
- 检查有无**短路**(用万用表测进线端通断);
- 送电后观察**表盘是否走字**,方向是否正确(三相表不得反转);
- 接线端子**压紧、无松动**,表箱接地良好。

## 五、考点提示

- ✅ 插座左零右火、上孔接地;开关接火线。
- ✅ 单相电能表:1、3 进(火、零),2、4 出(火、零),进出不能反。
- ✅ 电能表:电流线圈**串联**、电压线圈**并联**。
- ✅ 接完核对、检查短路,送电看走字。
- ⚠️ 易混点:单相表进出线序、三相表相序——接错会计量错误或表不转。

## 六、本节小结

- 配电线路:火进开关、左零右火、螺口灯头接线规范。
- 电能表:单相按进线出线对号,三相按相序接线。
- 电流串、电压并,接完必查、送电看表。
