# 14.3 电动机控制线路实操要点

## 本节导读

电动机控制线路接线(点动、自锁、正反转)是实操考核的重点项目。这一节从"接线前—接线中—检查—试车"四步梳理规范动作。

## 一、接线前的准备

1. **看懂原理图**:分清主电路和控制电路;
2. **核对元器件**:接触器(KM)、热继电器(FR)、按钮(SB)、熔断器(FU)、断路器(QF)是否齐全完好;
3. **确认无电**:操作前确认电源未接通(考核中一般由考官控制送电)。

## 二、接线步骤(以自锁控制为例)

**主电路**:

```
L1L2L3 ─► QF ─► FU ─► KM主触点 ─► FR ─► M(电动机)
```

**控制电路**:

```
L ─► FU ─► 停止按钮SB(常闭) ─► 启动按钮SB(常开) ─► KM线圈 ─► FR常闭 ─► N
                    │
                    └── KM辅助常开(自锁触点) 与启动按钮并联
```

接线要点:

- 启动按钮与**KM 辅助常开触点并联**,实现自锁(松手不停);
- 停止按钮、FR 常闭触点**串联**在控制回路中;
- 导线**颜色、编号**规范,长短合理,不跨线飞线。

## 三、接好后必做的检查(考官最看重)

1. **查接线是否正确**:对照原理图逐点核对;
2. **查自锁**:启动按钮两端应并联 KM 辅助常开触点;
3. **查接触器、继电器型号**:线圈电压与实际电源相符(如 380V/220V);
4. **查导线压接**:端子压紧、不外露裸线;
5. 用万用表**粗测回路通断**,确认无短路。

## 四、试车(送电)要点

- 试车前**再次确认接线无误**,请示考官后送电;
- 送电后先**空载试车**:按启动按钮,接触器吸合并自锁,电动机转动;
- 按停止按钮,电动机停止;
- 若电动机**反转**,说明相序接反(任调两根相线)。

## 五、正反转接线注意

- 正转接触器 KM1、反转接触器 KM2;
- 反转:把**两根相线对调**接到电动机;
- **互锁必须加**(KM1 常闭串入 KM2 回路,反之亦然),防止两个接触器同时吸合短路。

## 六、考点提示

- ✅ 自锁=启动按钮并联 KM 辅助常开。
- ✅ 停止按钮、FR 常闭串在控制回路。
- ✅ 接完必须检查,再申请试车。
- ✅ 反转对调两相,正反转要互锁。
- ⚠️ 扣分点:未检查就送电、接线错乱飞线、自锁漏接——都要扣分。

## 七、本节小结

- 主电路管"送电",控制电路管"开关"。
- 自锁靠并联辅助触点,保护靠串联常闭触点。
- 接线 → 检查 → 试车,三步缺一不可。

## 八、自测练习

1. (判断)自锁控制中,启动按钮应与接触器辅助常开触点并联。( )
2. (判断)控制回路中,停止按钮应串联在控制电路中。( )
3. (单选)电动机接线后反转,应()。
   A. 加大电流　B. 任调两根相线　C. 减小负载　D. 换电机
4. (判断)正反转控制必须加互锁,防止两接触器同时吸合造成相间短路。( )
5. (判断)接好线路后,应认真检查核对无误,再申请送电试车。( )
