# 3.2 触电类型与触电方式

## 本节导读

人为什么会触电?按"人和电源怎么接触"来分,主要有**单相触电、两相触电、跨步电压触电**几种。这一节把每种触电的电流路径、危险程度讲清楚——知道了哪条路危险,才能知道怎么避开。

## 一、触电事故的主要类型

| 类型 | 电流路径 | 危险程度 | 发生场合 |
|---|---|---|---|
| **单相触电** | 一根火线 → 人体 → 大地 | 常见、较危险 | 触及带电的相线 |
| **两相触电** | 一根火线 → 人体 → 另一根火线 | **最危险** | 同时触及两根火线 |
| **跨步电压触电** | 两脚之间形成电压 → 电流经双腿 | 视电压而定 | 高压线落地附近 |
| **接触电压触电** | 触摸带故障电压的设备外壳 | 较危险 | 设备漏电外壳带电 |

## 二、单相触电(最常见的触电)

人体某一部位**接触一根相线(火线)**,电流从火线经人体流入大地(或经零线),构成回路。

```
     火线(L) ──────● 人手
                      │ 人体
                      │
                      ▼
                     大地
```

- 在中性点直接接地的系统中,人体承受的电压接近**相电压(220 V)**,很危险;
- 占触电事故的大多数——因为日常工作接触最多的是单根相线。

## 三、两相触电(最危险的触电)

人体同时接触**两根相线**,电流从一根火线经人体流到另一根火线。

```
  火线L1 ──────● 左手
                   │ 人体(电流横穿胸部)
                   ▼
  火线L2 ──────● 右手
```

- 人体承受**线电压(380 V)**,比单相触电电压更高;
- 电流必然通过身体躯干,**极易穿过心脏**,致命风险最大。

> ⚠️ 重点:两相触电为什么最危险?两个原因——电压高(380V)+ 电流横穿心脏。

## 四、跨步电压触电

**高压线(或高压设备)断线落地点附近**,大地表面会形成不同的电位。人走进危险区,两脚之间出现电位差(电压),电流从一只脚经两腿流到另一只脚,就是**跨步电压触电**。

```
       落地点(高压)
           │
        ┌──┴──┐   ← 地面电位呈环形分布
        │      │
    脚A ●────● 脚B   ← 两脚之间形成电压
         电流经两腿
```

**正确逃生姿势**:发现高压线落地,**双脚并拢跳跃**或用单脚跳着离开危险区——让两脚电位尽量相同,避免形成跨步电压。

## 五、接触电压触电

电气设备外壳因绝缘损坏而带电(漏电),人**触摸外壳**时,电流经人体流入大地,称为接触电压触电。这就是为什么设备外壳要**接地保护**(第 11 章详讲)——外壳一旦接地,漏电电流直接流走,人触摸到时的接触电压就很小。

## 六、其他触电形式(了解)

- **高压电弧触电**:人距高压带电体太近,高压把空气击穿形成电弧,电流通过电弧伤人;
- **感应电压触电**:靠近高压线路的导体感应出电压,人接触时触电。

## 七、考点提示

- ✅ **两相触电最危险**(380 V + 电流穿胸)。
- ✅ **单相触电最常见**(220 V)。
- ✅ 高压线落地:双脚并拢跳跃逃离,避免跨步电压。
- ✅ 设备外壳漏电 → 接触电压触电 → 靠接地保护解决。
- ⚠️ 易混点:单相(一根火线对大地)与两相(两根火线之间)的区别,从"电流路径"理解。

## 八、本节小结

- 触电分单相、两相、跨步电压、接触电压等类型。
- 单相最常见、两相最危险;跨步电压靠"双脚并拢跳"逃生。
- 接地保护能大大降低接触电压触电的风险。
