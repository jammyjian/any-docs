# 第 3 章 电气安全基础知识

本章讲解电气安全最核心的知识:电流对人体的危害机理、触电的类型与方式、安全电压与安全电流、电气安全距离与安全防护措施、安全标识与警示标志。

**本章考点**:安全电压等级(42V、36V、24V、12V、6V)、工频安全电流值、跨步电压触电、单相触电 vs 两相触电、常见安全标识含义等,是理论机考的重中之重。

## 学习提示

- 安全电压的各档数值(42/36/24/12/6 V)必须记住,考试经常直接考。
- "安全电压"不等于"绝对安全",理解其适用条件很重要。
