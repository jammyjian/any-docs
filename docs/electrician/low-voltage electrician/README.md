# 低压电工考证学习文档

> 面向《特种作业操作证 · 低压电工作业》考证的系统化学习资料,覆盖理论机考与实操考核知识点,**重点在理论**。内容力求通俗易懂,概念讲解详细,适合零基础入门和考前复习。

## 什么是低压电工特种作业操作证

特种作业操作证(俗称"电工证"、"IC 卡证")是从事特种作业必须持有的上岗证,由**应急管理部门**(原安全生产监督管理部门)考核发证。低压电工是指从事 **1 kV 以下(不含 1 kV)**低压电气设备的安装、检修、运行、维护作业的人员。

- **证书样式**:IC 卡式,全国通用
- **有效期**:6 年
- **复审**:每 3 年复审一次
- **查验**:证书真伪可在应急管理部官网查询

## 考试形式

| 项目 | 说明 |
|---|---|
| 理论考试 | 计算机机考,约 100 题(单选 / 多选 / 判断),满分 100 分,**80 分及格** |
| 实操考核 | 现场操作 + 口述,考核仪表使用、电动机控制线路、安全操作、触电急救等 |
| 两科要求 | 理论和实操均合格,方可取得证书 |

## 如何使用本套文档

1. **按章节顺序学习**:先打基础(第 1~4 章)→ 学设备与元器件(第 5~8 章)→ 学系统与安全(第 9~13 章)→ 最后看实操与应试(第 14 章)。
2. 每节末尾设有「**考点提示**」和「**自测练习**」,先自己作答再对照参考答案。
3. 高频考点章节(如 3.3 安全电压、9.2 接地形式、11.2 接地接零)建议反复复习。
4. 结合真题练习:理解概念后再刷题,事半功倍。
