# 6.1 导线的种类与型号

## 本节导读

电线是电流的"路"。这一节认识最常见的导线:哪些是**裸导线**,哪些是**绝缘导线**,以及最关键的能力——**看懂型号**。看到 BV、BLV、BVR 能立刻说出是什么线,是电工的基本功。

## 一、导线的种类

### 1. 裸导线

没有绝缘层的导线,用于**架空线路**、母线等绝缘距离有保证的场合。

| 名称 | 型号 | 特点 |
|---|---|---|
| 铜绞线 | TJ | 导电好,贵 |
| 铝绞线 | LJ | 轻、便宜,用于架空线路 |
| 钢芯铝绞线 | **LGJ** | 铝线包裹钢芯,强度高,用于高压架空线 |

### 2. 绝缘导线

导线外面有绝缘层,用于低压配电线路、设备内部接线。

- **塑料绝缘线**:用聚氯乙烯(PVC)绝缘,最常用;
- **橡皮绝缘线**:用橡皮绝缘,柔软耐磨;
- 按芯线又分**单股(硬线)和多股(软线)**。

## 二、型号字母含义(必背)

看懂型号,先记字母:

| 字母 | 含义 |
|---|---|
| **B** | 布线用(绝缘导线) |
| **V** | 聚氯乙烯绝缘(塑料) |
| **L** | 铝(芯);没有 L 表示铜芯 |
| **R** | 软线(多股细丝) |
| **X** | 橡皮绝缘 |
| **Y** | 聚乙烯绝缘 |

### 常见导线型号举例

| 型号 | 含义 |
|---|---|
| **BV** | 铜芯聚氯乙烯绝缘导线(最常见的"硬线") |
| **BLV** | **铝**芯聚氯乙烯绝缘导线 |
| **BVR** | 铜芯聚氯乙烯绝缘**软线** |
| **BVV** | 铜芯聚氯乙烯绝缘**聚氯乙烯护套**线(两芯带护套) |
| **BX** | 铜芯橡皮绝缘导线 |
| **BLX** | 铝芯橡皮绝缘导线 |

> 💡 解读技巧:**先认材料、再认芯线**。如 BLV = B(布线)+L(铝)+V(聚氯乙烯绝缘)= 铝芯塑料绝缘线;没有 L 的就是铜芯(BV = 铜芯塑料线)。

> ⚠️ 高频考点:**BV 是铜芯,BLV 是铝芯**——判断导线芯线材质,就看有没有 L。

## 三、铜芯 vs 铝芯怎么选

| 对比项 | 铜芯 | 铝芯 |
|---|---|---|
| 导电性 | 好 | 较差 |
| 抗腐蚀 | 好 | 差(接头易氧化发热) |
| 价格 | 贵 | 便宜 |
| 重量 | 重 | 轻 |
| 用途 | 低压配电、设备接线首选 | 架空线路、部分低压线路 |

> 💡 现在低压线路普遍**优先用铜芯**;铝芯多用于架空线路。铝线接头氧化是安全隐患(接触电阻变大发热),要特别注意。

## 四、考点提示

- ✅ 型号字母:B=布线、V=聚氯乙烯、L=铝芯、R=软、X=橡皮。
- ✅ **BV=铜芯塑料线,BLV=铝芯塑料线**。
- ✅ 有 L 是铝芯,没 L 是铜芯。
- ⚠️ 易混点:BV 与 BLV 只差一个 L,材质完全不同。

## 五、本节小结

- 导线分裸导线(架空用)和绝缘导线(低压配电用)。
- 型号看字母:先辨材料(V=塑料、X=橡皮),再看芯线(L=铝、无L=铜)。
- 铜芯导电好、铝芯便宜,低压线路多用铜芯。

   A. 铝芯　B. 铜芯　C. 塑料绝缘　D. 软线
