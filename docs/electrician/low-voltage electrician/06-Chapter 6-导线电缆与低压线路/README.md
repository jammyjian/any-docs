# 第 6 章 导线电缆与低压线路

本章讲解低压电气线路中导线的种类与型号、电缆的种类与选用、导线截面的选择方法(载流量、电压损失、机械强度),以及低压线路的敷设方式与连接工艺。

**本章考点**:导线型号字母含义(BV、BLV、BVV 等)、相同截面导线载流量口诀(二点五下乘以九等)、多股导线连接工艺、导线连接处电阻不能增大等。

## 学习提示

- 导线型号识别是常考题,要熟记各字母含义(如 B=布线用, V=聚氯乙烯绝缘, R=软线)。
- 截面选择是计算题考点,记住"先按载流量、再校电压损失、后验机械强度"的顺序。
