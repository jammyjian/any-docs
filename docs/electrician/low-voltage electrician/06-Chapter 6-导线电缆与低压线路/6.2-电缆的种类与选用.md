# 6.2 电缆的种类与选用

## 本节导读

电缆比导线"豪华"——里面多了一层又一层保护,能应付地下、潮湿、受力的环境。这一节认识电缆的结构、型号(VV、YJV)和选用原则。

## 一、电缆的结构

一根电力电缆,从里到外一般是:

```
┌──────────────────────┐
│  线芯(导体)           │  导电部分,一芯或多芯
│  绝缘层               │  芯线外面的绝缘
│  护套层(外护层)       │  保护绝缘和线芯
│  铠装(部分电缆)       │  钢带等,抗机械损伤
└──────────────────────┘
```

- **线芯**:导电主体(铜或铝),可单芯、可多芯;
- **绝缘层**:保证芯线之间、芯线与地之间的绝缘;
- **护套层**:机械保护,防止潮气、腐蚀;
- **铠装层**(部分):增加抗压、抗拉能力,用于直埋敷设。

## 二、电缆的型号

常见低压电力电缆型号:

| 型号 | 含义 |
|---|---|
| **VV** | 铜芯聚氯乙烯绝缘聚氯乙烯护套电缆 |
| **VLV** | 铝芯聚氯乙烯绝缘聚氯乙烯护套电缆 |
| **YJV** | 铜芯**交联聚乙烯**绝缘聚乙烯护套电缆(现代常用,耐温高) |
| **YJLV** | 铝芯交联聚乙烯绝缘电缆 |
| 加数字 | 如 VV22、YJV22,**22 表示带钢带铠装**(可直埋) |

> 💡 解读:字母规律和导线类似——**V=聚氯乙烯,YJ=交联聚乙烯,没有 L 是铜芯**;末尾数字 22/23 表示铠装层。

## 三、电缆的选用原则

1. **按电压等级**:电缆额定电压 ≥ 线路工作电压(低压电缆 0.6/1 kV 等);
2. **按敷设方式**:
   - **直埋地下** → 选**铠装电缆**(VV22、YJV22),能抗压;
   - 穿管、桥架敷设 → 普通电缆即可;
3. **按环境**:
   - 潮湿、腐蚀环境 → 选防水防腐型护套;
   - 高温环境 → 选交联聚乙烯(YJV)等耐热型号;
4. **按载流量**:电缆截面要满足负载电流(见 6.3 节);
5. **按芯数**:单相负荷选两芯或三芯,三相选四芯/五芯(含中性线、保护线)。

## 四、电缆敷设的安全要求

- 电缆埋地深度要足够(一般 ≥ 0.7 m),上面铺设保护盖板;
- 电缆与其他管道(燃气管、热力管)要保证间距;
- 电缆两端和接头处要**封堵防潮**,接头工艺要规范;
- 电缆线路要设标识,便于维护和防止误挖。

## 五、考点提示

- ✅ 电缆结构:线芯、绝缘层、护套层(部分带铠装)。
- ✅ VV=铜芯塑料绝缘塑料护套,YJV=交联聚乙烯(耐高温更好)。
- ✅ 直埋地下选**铠装电缆**(型号带 22)。
- ⚠️ 易混点:型号中 V 和 YJ 是绝缘材料,末尾数字表示铠装/外护套。

## 六、本节小结

- 电缆 = 线芯 + 绝缘 + 护套(可选铠装)。
- VV 是 PVC 电缆,YJV 是交联聚乙烯电缆,22 表示铠装。
- 直埋要铠装、高温选交联、截面按载流量。
