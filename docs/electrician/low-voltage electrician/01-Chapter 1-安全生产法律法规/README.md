# 第 1 章 安全生产法律法规

本章讲解与低压电工取证、作业直接相关的法律法规体系:法律层次与主要依据、《安全生产法》要点、特种作业人员管理制度、电工岗位职责与职业道德,以及违反安全规定所需承担的法律责任。

**本章考点**:特种作业操作证的有效期(6 年)与复审周期(3 年)、持证上岗要求、"安全第一、预防为主"的方针、特种作业证禁止转借转让等,多为基础记忆题。
