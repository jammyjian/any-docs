# 1.2 特种作业人员管理制度

## 本节导读

"特种作业"是电工证的本源。为什么电工要考证、证的有效期多长、多久复审一次、报考要过哪些关——这些制度性知识是机考的固定出题点,而且都是**数字题、记忆题**,记住了就拿分。

## 一、什么是特种作业

**特种作业**,指容易发生人员伤亡事故,对操作者本人、他人及周围设施的安全有重大危险的作业。国家规定这类作业的人员必须经过专门培训、考核合格,取得资格证书后才能上岗。

常见特种作业目录(部分):

- ✅ **电工类**:低压电工作业、高压电工作业、电力电缆作业、继电保护作业、电气试验作业、防爆电气作业
- 焊接与热切割作业(焊工)
- 高处作业(架子工、登高作业)
- 制冷与空调作业
- 危险化学品安全作业 等

> 💡 我们考的**低压电工作业**,就是特种作业目录中的电工类之一,对应的证书叫《特种作业操作证(低压电工作业)》。

## 二、考证流程:五步拿证

```
报名培训 → 完成学时 → 理论机考 → 实操考核 → 考核合格发证
```

1. **报名培训**:到有资质的培训机构报名(应急管理部门认可的安全培训机构),提交身份证明等材料。
2. **完成学时**:按要求完成安全技术培训学时(理论和实操都要培训)。
3. **理论机考**:计算机考试,考安全生产知识与电工专业知识,满分 100 分,**80 分及格**。
4. **实操考核**:现场考核仪表使用、线路接线、安全操作、急救等技能。
5. **发证**:两科合格后,由应急管理部门颁发《特种作业操作证》。

## 三、报考条件(记数字)

| 条件 | 要求 |
|---|---|
| 年龄 | 年满 **18 周岁**,不超过国家法定退休年龄 |
| 文化程度 | 初中及以上文化程度 |
| 身体条件 | 身体健康,无妨碍从事低压电工工作的疾病和生理缺陷(如色盲、癫痫等) |
| 安全技术 | 具备必要的安全技术知识与技能 |

## 四、证书管理与复审(重点!)

特种作业操作证是 **IC 卡式**,全国通用,样式类似一张信用卡,上面有照片、姓名、作业类别、有效期等信息。

- **有效期:6 年**。到期需要换发新证。
- **复审周期:每 3 年复审一次**。复审由持证人到原考核发证机关或其委托的机构办理。
- 证书在**全国范围内有效**,跨省也能用。
- 证书是**上岗凭证**:作业时必须随身携带或能出示;**不得转借、转让、涂改、伪造**。
- 证书真伪可在**应急管理部官网**查询(输入身份证号/证书编号)。

> ⚠️ 高频考点:"6 年有效期、3 年复审"这两个数字几乎是逢考必出,务必记牢。

## 五、为什么必须持证上岗

《安全生产法》规定:生产经营单位的特种作业人员**必须按照国家有关规定经专门的安全作业培训,取得相应资格,方可上岗作业**。

无证上岗的后果:
- 属于违法行为,用人单位要承担法律责任(可能被责令改正、罚款、停产停业整顿);
- 一旦发生事故,无证作业人员的责任更大;
- 出了事故保险理赔也可能受影响。

## 六、考点提示

- ✅ 低压电工操作证有效期 **6 年**,每 **3 年**复审一次。
- ✅ 报考年龄要求:年满 **18 周岁**。
- ✅ 理论机考合格线:**80 分**(满分 100 分)。
- ✅ 证书**全国通用**,**禁止转借转让**。
- ⚠️ 易混点:复审周期(3 年)和有效期(6 年)是两个不同概念,别搞混。

## 七、本节小结

- 低压电工属于**特种作业**,证书由**应急管理部门**考核发证。
- 考证五步:报名 → 培训 → 理论机考(80 分及格)→ 实操考核 → 发证。
- 证书 **6 年有效、3 年复审、全国通用、禁止转借**。
