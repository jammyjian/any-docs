# 2.5 交流电路基础

## 本节导读

到目前为止讲的"水流"都是**直流**——方向不变。但家里和工厂里用的电,是**交流电**,电流方向每秒钟要来回变 50 次。这一节讲清交流电的三大要素、**有效值**怎么算,以及最重要的**三相交流电**和它的两种接法(星形/三角形)。

## 一、直流电与交流电的区别

| 对比项 | 直流电(DC) | 交流电(AC) |
|---|---|---|
| 电流方向 | 始终不变 | 周期性改变方向 |
| 大小 | 基本不变 | 随时间按正弦规律变化 |
| 来源 | 电池、直流发电机 | 交流发电机 |
| 例子 | 干电池、蓄电池 | 市电(220 V/380 V) |

**交流电的波形**是正弦波,就像起伏的波浪:

```
  幅值▲
   Um │    ╱╲
      │   ╱  ╲
      │  ╱    ╲      ╱╲
   0 ─┼────╲────╲────╱────╲────► t
      │     ╲    ╱  ╲╱
   -Um│      ╲╱
```

## 二、正弦交流电的三要素

描述正弦交流电,需要三个"要素":

1. **幅值(最大值)Um**:波形能达到的最高值;
2. **频率 f / 周期 T**:
   - **周期 T**:完成一次完整变化需要的时间,单位秒(s);
   - **频率 f**:每秒钟变化的次数,单位**赫兹(Hz)**;
   - 关系:`T = 1/f`。我国工频交流电 **f = 50 Hz**,则 `T = 1/50 = 0.02 s`;
3. **初相位**:起始时刻的角度位置(决定波形从哪开始),做题时一般默认初相位为 0。

## 三、有效值:交流电的"等效直流值"

交流电大小一直在变,那"220 V"到底是多少?——**有效值**!

**有效值**:交流电通过电阻时,一个周期内产生的热量,与某个**大小不变的直流电**在同样时间内产生的热量相等,那么这个直流电的数值就是该交流电的**有效值**。

- 正弦交流电:**有效值 = 最大值 / √2 ≈ 0.707 × 最大值**
  - `U = Um / √2`,`I = Im / √2`
- 反过来:**最大值 = √2 × 有效值 ≈ 1.414 × 有效值**
  - 市电有效值 220 V → 最大值 `Um = 220 × 1.414 ≈ 311 V`
  - 380 V 线电压 → 最大值 ≈ 537 V

> ⚠️ 常考:我们说的"220 V""380 V"都是**有效值**,不是最大值;设备铭牌上标的也是有效值。

## 四、三相交流电

### 1. 什么是三相交流电

发电机发出三组交流电,它们在时间上**相差 120°**(1/3 个周期),组成三相交流电。每一"相"用 L1、L2、L3 表示(也写作 A、B、C 相)。

**为什么用三相?** 三相电功率大、效率高,还能产生**旋转磁场**(这正是电动机能转起来的根本原因,第 8 章详讲)。

### 2. 两个关键概念:相电压与线电压

- **相电压**:每相绕组两端的电压(即"火线"与"零线/中性线"之间的电压);
- **线电压**:任意两根火线之间的电压。

### 3. 星形(Y)接法与三角形(Δ)接法

**星形接法(Y)**:三组线圈的末端连在一起(称中性点),首端引出三根火线。

```
        L1(火线)
    ┌───┐
  ｜线圈1｜●────┐
    └───┘      ├─ 中性点(N/零线)
  ｜线圈2｜●────┘
  ｜线圈3｜●───────► 实际是三条线圈接法示意
```

**关键关系(星形)**:
```
线电压 U线 = √3 × 相电压 U相  (√3 ≈ 1.732)
线电流 I线 = 相电流 I相
```
我们日常:相电压 220 V,线电压 380 V(`220 × √3 ≈ 380`)。

**三角形接法(Δ)**:首尾相接成闭合三角形,没有中性点。

**关键关系(三角形)**:
```
线电压 U线 = 相电压 U相
线电流 I线 = √3 × 相电流 I相
```

> 💡 记忆口诀:**"Y 形升电压、Δ 形升电流"**——星形接法线电压是相电压的 √3 倍;三角形接法线电流是相电流的 √3 倍。

### 4. 三相四线制与三相五线制

- **三相四线制**:三根火线 + 一根零线(中性线),用于 220/380 V 供电;
- **三相五线制**:三根火线 + 零线 + 保护接地线(PE),即 TN-S 系统(第 9 章详讲)。

## 五、交流电路里的三种"阻碍"(简要了解)

交流电通过不同元件时,受到的阻碍不完全相同:

| 元件 | 阻碍类型 | 特点 |
|---|---|---|
| 电阻 R | 电阻 | 阻碍与频率无关 |
| 电感 L | 感抗 XL | 频率越高阻碍越大(阻止电流突变) |
| 电容 C | 容抗 XC | 频率越高阻碍越小(允许电流变化) |

> 💡 这一部分记住"**电感通直流阻交流、电容通交流阻直流**"即可,深层次内容(功率因数、无功功率)在考证里不深究。

## 六、考点提示

- ✅ 我国工频交流电频率 **50 Hz**,周期 0.02 s。
- ✅ 220 V、380 V 均为**有效值**;最大值 = 有效值 × √2 ≈ 1.414 倍。
- ✅ 星形接法:线电压 = √3 × 相电压(220 → 380);三角形接法:线电流 = √3 × 相电流。
- ✅ 电感"通直流阻交流",电容"通交流阻直流"。
- ⚠️ 易混点:√3(≈1.732)与 √2(≈1.414)别搞混——√3 是相线电压关系,√2 是有效值/最大值关系。

## 七、本节小结

- 交流电方向、大小随时间正弦变化,由幅值、频率、初相位三要素描述。
- 有效值 = 最大值/√2;市电 220 V 是有效值,最大值约 311 V。
- 三相交流:星形接法线电压 = √3×相电压,三角形接法线电流 = √3×相电流。
- 我国工频 50 Hz,周期 0.02 s。
