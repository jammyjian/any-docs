# 2.2 电路的组成

## 本节导读

你已经认识了电流、电压、电阻三个"主角",这一节看它们怎么凑成一台戏——**一个完整的电路由哪些部分组成**,电路有哪几种"状态",以及怎么用电路图符号把它画出来。

## 一、什么是电路

**电路**,就是**电流流通的路径**。最简单理解:把电源、用电器、导线接起来,电流从电源的一端出发,经过用电器,再回到电源的另一端,形成一个闭合的回路。

## 二、电路的四大基本组成

一个最简单的电路,至少要有四样东西:

```
      ┌─────────────┐
      │    电源      │  ← 提供电压(推动力)
      └──────┬──────┘
             │ 导线
        ┌────┴────┐
        │  开关    │  ← 控制电路通断
        └────┬────┘
             │ 导线
      ┌──────┴──────┐
      │    负载     │  ← 消耗电能,把电能转成其他能量
      └─────────────┘
```

| 组成 | 作用 | 例子 |
|---|---|---|
| **电源** | 提供电压,把其他能量转成电能 | 电池、发电机、配电变压器 |
| **负载(用电设备)** | 消耗电能,把电能转成其他能量 | 灯泡、电动机、电炉 |
| **导线** | 连接各元件,让电流流通 | 铜线、电缆 |
| **开关(含保护装置)** | 控制电路的通断、保护电路 | 刀开关、断路器、熔断器 |

> 💡 **水流类比**:电源=水泵(提供压力),导线=水管,开关=阀门,负载=水轮机(消耗水流做功)。水泵不给力(电压低)、阀门关着(断开)、水管漏了(短路),水轮机都转不起来。

## 三、电路的三种状态

| 状态 | 含义 | 后果/特点 |
|---|---|---|
| **通路(闭路)** | 电路处处接通,电流流通 | 正常工作,负载做功 |
| **断路(开路)** | 某处断开,电流无法流通 | 电路无电流,负载不工作 |
| **短路** | 电源两端被直接接通,中间几乎无负载 | **电流极大,烧坏设备、引发火灾**,必须防止 |

> ⚠️ **短路是电工大忌**:短路时电流不经过(或只经过很小)负载,直接构成低阻回路,电流瞬间飙升,产生大量热量,烧毁导线和设备,甚至引发火灾和爆炸。所以低压电器里专门有"短路保护"(熔断器、断路器)——第 5 章会讲。

## 四、电路图与常用符号

**电路图**是用规定的符号表示电路连接关系的图,电工必须看得懂、画得对。几个最常用的符号先认识:

| 元件 | 图形符号 | 文字符号 |
|---|---|---|
| 电池(电源) | `—| |—` | E 或 GB |
| 灯泡 | `—ⓧ—` | EL |
| 电阻 | `—▭▭—` | R |
| 开关 | `—/——` | S 或 SA |
| 导线 | `———` | L(火线)/N(零线) |
| 熔断器 | `—☒—` | FU |
| 电动机 | `M`(圆圈内) | M |

> 💡 完整系统的图形符号、文字符号识别,在第 9.4 节"电工识图基础"详细展开,这里先混个脸熟。

## 五、考点提示

- ✅ 电路四大组成:**电源、负载、导线、开关(保护装置)**——缺一不可(考试常考"下列哪个不是电路的必要组成部分")。
- ✅ 短路 = 电流不经过负载直接连通电源两端,**电流极大**,必须严防。
- ✅ 断路 = 电路断开,无电流、负载不工作。
- ⚠️ 易混点:短路和断路是两个相反的概念,别搞反。

## 六、本节小结

- 电路是电流流通的路径,由电源、负载、导线、开关四要素组成。
- 三种状态:通路(工作)、断路(不工作)、短路(危险)。
- 短路电流极大,是电气火灾的主要原因之一。

## 七、自测练习

1. (单选)电路的基本组成部分不包括()。
   A. 电源　B. 负载　C. 仪表　D. 导线
2. (判断)短路时电路中的电流会急剧增大,可能烧毁设备和引发火灾。( )
3. (单选)当电路某处断开,电流无法流通,这种状态称为()。
   A. 通路　B. 短路　C. 断路　D. 过载
4. (判断)开关的作用是控制电路的通断。( )
5. (单选)把电源的正负极用导线直接连通,中间没有负载,这种情况属于()。
   A. 断路　B. 短路　C. 正常通路　D. 过载运行
