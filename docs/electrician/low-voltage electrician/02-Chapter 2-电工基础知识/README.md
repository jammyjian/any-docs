# 第 2 章 电工基础知识

本章是全套文档的基础,讲解电工必须掌握的最基本概念:电、电流、电压、电阻、电路组成、串联并联电路、欧姆定律与电功率,以及交流电路(单相与三相)、电与磁、常用名词单位。

**本章考点**:欧姆定律计算、串并联电路特点与计算、星形/三角形接法下相电压与线电压的关系、交流电有效值等,是理论机考计算题的题源。
