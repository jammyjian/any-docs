# 2.3 串联与并联电路

## 本节导读

电路里的元件怎么"排队",决定了电流怎么走。**串联**和**并联**是两种最基本、也最重要的连接方式——家里的灯泡、开关、插座、电器,说到底都是这两种方式的组合。这一节把它们的规律讲透,并给出计算例题。

## 一、串联电路:一个接一个,连成一串

**串联**,就是元件**首尾相接,连成一串**,电流只有一条通路。

```
───[R1]───[R2]───[R3]───
```

### 串联电路的三大规律

1. **电流处处相等**:`I = I1 = I2 = I3`——电流只有一条路,在哪儿都一样多。
2. **总电压等于各分电压之和**:`U = U1 + U2 + U3`——电压被"分着用"。
3. **总电阻等于各电阻之和**:`R = R1 + R2 + R3`——电阻越串越大。

**分压原理**:串联电路中,电阻大的元件分到的电压大。即 `U1 : U2 = R1 : R2`(电压按电阻成正比分配)。

> 💡 **水流类比**:串联就像几段管子接成一长条,流量(电流)全程一样;但每一段管子的"水压降"(电压)加起来等于总水压。

## 二、并联电路:并排连接,各有各的路

**并联**,就是元件**并排连在两端之间**,电流有多条通路。

```
────┬─────[R1]────┬────
    ├─────[R2]────┤
    └─────[R3]────┘
```

### 并联电路的三大规律

1. **电压处处相等**:`U = U1 = U2 = U3`——两端之间电压相同。
2. **总电流等于各支路电流之和**:`I = I1 + I2 + I3`——各支路分流后汇合。
3. **总电阻的倒数等于各支路电阻倒数之和**:`1/R = 1/R1 + 1/R2 + 1/R3`——**电阻越并越小**。

**分流原理**:并联电路中,电阻小的支路分到的电流大。即 `I1 : I2 = R2 : R1`(电流按电阻成反比分配)。

> 💡 **水流类比**:并联就像几根管子并排供水,每根管子两端的水压(电压)一样;但总流量(总电流)等于各根管子流量之和,管子越粗(电阻越小)流得越多。

**两个电阻并联的快速公式**(考试常用):

```
R = R1·R2 / (R1 + R2)
```

## 三、串并联对比表(必背)

| 项目 | 串联 | 并联 |
|---|---|---|
| 连接方式 | 首尾相接 | 两端并接 |
| 电流 | 处处相等 I=I1=I2 | 总电流=各支路之和 I=I1+I2 |
| 电压 | 总电压=各分压之和 U=U1+U2 | 处处相等 U=U1=U2 |
| 总电阻 | R=R1+R2(越串越大) | 1/R=1/R1+1/R2(越并越小) |
| 分配规律 | 电压按电阻成正比分压 | 电流按电阻成反比分流 |
| 一盏灯坏 | 整串全灭 | 其他支路仍工作 |

## 四、计算例题

### 例题 1(串联)

R1 = 2 Ω、R2 = 4 Ω 串联,接在 12 V 电源上。求:总电阻、总电流、R1 两端电压。

**解**:
- 总电阻 `R = R1 + R2 = 2 + 4 = 6 Ω`
- 总电流 `I = U/R = 12/6 = 2 A`(串联电流处处相等)
- R1 分压 `U1 = I·R1 = 2 × 2 = 4 V`
- 验算:R2 分压 `U2 = I·R2 = 2 × 4 = 8 V`,`U1 + U2 = 12 V = U` ✓

### 例题 2(并联)

R1 = 4 Ω、R2 = 6 Ω 并联,接在 12 V 电源上。求:总电阻、各支路电流、总电流。

**解**:
- 总电阻 `R = R1·R2/(R1+R2) = 4×6/(4+6) = 24/10 = 2.4 Ω`
- R1 支路电流 `I1 = U/R1 = 12/4 = 3 A`
- R2 支路电流 `I2 = U/R2 = 12/6 = 2 A`
- 总电流 `I = I1 + I2 = 3 + 2 = 5 A`
- 验算:`I = U/R = 12/2.4 = 5 A` ✓

## 五、生活中的串并联

- **家用电器全是并联**:插座之间、电器之间都并联接在 220 V 上,这样电压一样、互不影响(一个坏了其他还能用)。并联接法也是安全的要求——串联的话,一个开关就能控制整屋,而且各电器电压会分不均匀。
- **串联的典型**:节日小彩灯(一串)、电池串联(手电筒里两节电池正负极首尾相接提高电压)。

## 六、考点提示

- ✅ 串联:**电流相等、电压相加、电阻相加**;并联:**电压相等、电流相加、电阻变小**。
- ✅ 两电阻并联公式 `R = R1R2/(R1+R2)`,考试计算高频。
- ✅ 家用电器应该**并联**连接,不是串联。
- ⚠️ 易混点:串并联的"分配"方向相反——串联按电阻分电压(正比),并联按电阻分电流(反比)。

## 七、本节小结

- 串联:一条路,电流处处相等,总电阻变大,按电阻分压。
- 并联:多条路,电压处处相等,总电阻变小,按电阻分流。
- 计算遵循欧姆定律 + 串并联规律,先判连接方式再套公式。
