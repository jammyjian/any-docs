# 2.6 电与磁及电磁感应

## 本节导读

"电"和"磁"是一家:电可以生磁,磁也可以生电。这两条规律催生了电动机、发电机、变压器、电磁铁、继电器等几乎所有重要的电气设备。这一节把"电生磁、磁生电"讲清楚——它是理解第 7 章变压器、第 8 章电动机的基础。

## 一、磁的基本概念

- **磁体**:有吸引铁、钴、镍能力的物体(磁铁、地球都是磁体)。
- **磁极**:磁体上磁性最强的两端,分**N 极(北极)和 S 极(南极)**。
  - 规则:同名磁极相斥,异名磁极相吸。
- **磁场**:磁体周围存在看不见、摸不着的特殊物质——磁场。
- **磁感线**:用来形象描述磁场的假想曲线:
  - 方向:在磁体**外部,从 N 极出发回到 S 极**;在磁体**内部,从 S 极到 N 极**,形成闭合曲线;
  - 磁感线越密,磁场越强;磁感线是**闭合的、不相交**的。

```
   N ────────►  S      (磁体外部:从 N 到 S)
   ▲                 │
   └─────────────────┘   (内部:从 S 到 N,闭合)
```

## 二、电流的磁效应:电生磁

**电流通过导体时,周围会产生磁场**——这是丹麦物理学家**奥斯特**发现的,叫电流的磁效应。

- 通电直导线周围产生磁场,磁感线是以导线为圆心的一圈圈同心圆;
- 电流方向与磁场方向的关系,用**右手螺旋定则(安培定则)**判断:右手握住导线,**四指弯向电流方向,大拇指指向磁感线方向**(或反向记忆)。

> 💡 通俗理解:电线一通电,周围就像围了一圈"看不见的磁力",能把指南针吸得乱转。**电流一停,磁场消失。**

## 三、电磁铁与电磁继电器

**电磁铁** = 通电螺线管 + 铁芯,电流通过时产生磁场,磁力把铁芯磁化,从而吸引衔铁。

- 特点:**电流通,有磁力;电流断,磁力消失**——电一断,吸力立刻没了(这点和永久磁铁不同)。
- 应用:**电磁继电器**用"小电流控制大电流"——弱电流控制电磁铁通断,电磁铁再带动触点接通或断开主电路。这就是接触器、继电器的原理基础(第 5 章详讲)。

## 四、电磁感应:磁生电

**电磁感应**是英国物理学家**法拉第**发现的:

> 当**穿过闭合回路的磁通量发生变化**时,回路中会产生**感应电流**;如果回路不闭合,则在两端产生**感应电动势**。

**一句话**:变化的磁,能生电。

**感应电动势的大小**:
```
E = N · ΔΦ / Δt
```
即与线圈匝数 N 和磁通变化快慢(ΔΦ/Δt)有关——**磁通变化越快、线圈匝数越多,感应电动势越大**。

> 💡 **水流类比**:磁通变化就像"水位突降",变化越猛,产生的水流(电流)越大。发电机、变压器靠的都是这个原理。

**楞次定律**:感应电流的方向,总是**阻碍**引起它的磁通变化。通俗记:**"来拒去留"**——磁通增了就想办法不让它增,减了就想办法不让它减。判断感应电流方向时用右手定则。

## 五、自感与互感

- **自感**:线圈自身电流变化时,在线圈内产生的感应电动势,阻碍电流的变化。
- **互感**:一个线圈中电流变化,在**邻近另一个线圈**中产生感应电动势。

> ⚠️ **重点**:**互感是变压器的工作原理**——初级线圈的电流变化,通过共同的铁芯磁路,在次级线圈中感应出电压。所以**变压器只能变交流,不能变直流**(直流电流不变化,磁通不变,不产生感应)。这点第 7 章会反复用到。

## 六、电与磁的完整关系图

```
通电导线 ──产生──► 磁场(电流的磁效应)      → 电磁铁、继电器
磁场变化 ──产生──► 感应电动势(电磁感应)      → 发电机、变压器
     两者都由"变化的电流/磁通"联系在一起
```

## 七、考点提示

- ✅ 磁感线在磁体外部从 **N 极到 S 极**,是**闭合曲线**。
- ✅ 电流的磁效应:通电导线周围产生磁场(奥斯特)。
- ✅ 电磁感应:磁通量变化产生感应电动势(法拉第);**变压器靠互感原理,只能变交流**。
- ✅ 电磁铁"有电有磁力、断电失磁力",用于电磁继电器控制大电流。
- ⚠️ 易混点:电生磁(奥斯特/电流的磁效应)和磁生电(法拉第/电磁感应)方向相反,别记反。

## 八、本节小结

- 磁体有 N、S 两极,磁感线从 N 到 S(外部)闭合。
- 电流的磁效应:电生磁 → 电磁铁、继电器。
- 电磁感应:磁生电 → 发电机、变压器。
- 变压器靠互感,只能变换交流,不能变换直流。
